## 1. 통합 아키텍처 개요

### 1.1 통합 목표

현재 분산된 GrowAI 서비스들(LearnForm, LMS, MAP 등)을 **단일 Vite + React 애플리케이션**으로 통합한다.
`growai.co.kr` 도메인 하나에서 모든 서비스를 운영하여 다음을 달성한다.

- **사용자 경험 통일**: 하나의 URL, 하나의 인증, 일관된 UI
- **개발 효율 극대화**: 공통 컴포넌트/컨텍스트 재사용, 중복 코드 제거
- **운영 단순화**: 단일 빌드, 단일 배포, 단일 모니터링

### 1.2 기술 선택 근거

| 항목 | 선택 | 근거 |
|------|------|------|
| 번들러 | **Vite 6** | 빠른 HMR, ESM 네이티브, 플러그인 생태계 |
| UI 프레임워크 | **React 19** | 팀 숙련도, 컴포넌트 생태계, 커뮤니티 |
| 라우팅 | **React Router v7** | SPA 라우팅 표준, 중첩 라우트, 코드 스플리팅 지원 |
| 스타일링 | **Tailwind CSS v4** | 유틸리티 기반, 디자인 토큰 호환, 빠른 개발 |
| 상태 관리 | **Zustand** | 가볍고 직관적, 보일러플레이트 최소 |
| 다국어 | **react-i18next** | 검증된 i18n 솔루션, 네임스페이스 지원 |

### 1.3 전체 구조도

```
growai.co.kr (단일 도메인)
  │
  ├── Nginx (리버스 프록시 + SPA 폴백)
  │
  └── Vite + React SPA
       ├── / .................. 포털 (서비스 허브)
       ├── /learnform ........ 런폼
       ├── /lms/* ............ LMS
       ├── /map .............. Manufacturing AI Platform
       ├── /vls .............. Video Lecture System
       ├── /vas .............. Video Auto Summary
       ├── /ccb .............. Customer Care Bot
       ├── /ccs .............. Claude Code Skill
       ├── /cdn .............. Content Delivery Network
       └── /cms .............. Construction Management System
```

### 1.4 React Router 기반 라우팅 전략

```tsx
// src/router.tsx
const router = createBrowserRouter([
  {
    path: "/",
    element: <RootLayout />,
    children: [
      { index: true, element: <PortalPage /> },
      { path: "learnform/*", lazy: () => import("./features/learnform/routes") },
      { path: "lms/*", lazy: () => import("./features/lms/routes") },
      { path: "map/*", lazy: () => import("./features/map/routes") },
      { path: "vls/*", lazy: () => import("./features/vls/routes") },
      { path: "vas/*", lazy: () => import("./features/vas/routes") },
      { path: "ccb/*", lazy: () => import("./features/ccb/routes") },
      { path: "ccs/*", lazy: () => import("./features/ccs/routes") },
      { path: "cdn/*", lazy: () => import("./features/cdn/routes") },
      { path: "cms/*", lazy: () => import("./features/cms/routes") },
    ],
  },
]);
```

핵심 원칙:

- **Lazy Loading**: 각 서비스 모듈은 `lazy()`를 통해 필요 시에만 로드
- **중첩 라우트**: `RootLayout`이 공통 헤더/사이드바/푸터를 관리
- **코드 스플리팅**: 서비스별 독립 청크로 분리하여 초기 로딩 최소화

## 2. 소스 통합 구조

### 2.1 LearnForm V2 (Next.js) -> Vite/React 전환

LearnForm V2는 현재 Next.js 14 App Router 기반이다. 단일 SPA로 통합하기 위해 Vite/React로 전환한다.

#### 전환 대상 매핑

| Next.js (현재) | Vite/React (전환 후) | 비고 |
|----------------|---------------------|------|
| `app/page.tsx` | `features/learnform/pages/LandingPage.tsx` | 서버 컴포넌트 -> 클라이언트 컴포넌트 |
| `app/dashboard/` | `features/learnform/pages/Dashboard/` | 레이아웃 분리 |
| `app/learn/` | `features/learnform/pages/Learn/` | CREATOR 7단계 UI |
| `app/review/` | `features/learnform/pages/Review/` | FKDS 순환 UI |
| `app/login/` | `shared/pages/Login/` | 공통 인증으로 이관 |
| `app/register/` | `shared/pages/Register/` | 공통 인증으로 이관 |
| `app/demo/` | `features/learnform/pages/Demo/` | |
| `components/` | `shared/components/` 또는 `features/learnform/components/` | 공통 여부에 따라 분리 |
| `hooks/` | `shared/hooks/` 또는 `features/learnform/hooks/` | 공통 여부에 따라 분리 |
| `stores/` | `shared/stores/` 또는 `features/learnform/stores/` | Zustand 유지 |
| `i18n/` | `shared/i18n/` | 공통 다국어로 통합 |
| `lib/` | `shared/lib/` | API 클라이언트 등 |

#### 전환 시 주의 사항

- **서버 컴포넌트 제거**: Next.js의 `use server`, `generateMetadata` 등 서버 전용 기능은 클라이언트 방식으로 대체
- **next/image -> img 또는 커스텀 컴포넌트**: Next.js 이미지 최적화를 자체 구현 또는 제거
- **next/link -> React Router Link**: 라우팅 연동 변경
- **next/router -> useNavigate/useParams**: React Router 훅으로 교체
- **API Routes 제거**: 백엔드 API(FastAPI)로 직접 호출
- **미들웨어 -> React Router loader/action**: 인증 체크 등 이관

### 2.2 GrowAI-LMS V4 -> 기존 구조 유지

LMS V4는 이미 Vite + React 기반이므로 구조를 크게 변경하지 않는다.

#### 통합 방법

```
기존 GrowAI-LMS-V4/
  src/
    pages/         →  features/lms/pages/
    components/    →  features/lms/components/ (LMS 전용)
                   →  shared/components/ (공통으로 승격)
    contexts/      →  shared/contexts/ (ThemeContext, LanguageContext)
    hooks/         →  features/lms/hooks/ 또는 shared/hooks/
    i18n/          →  shared/i18n/ (통합)
    utils/         →  shared/utils/ 또는 features/lms/utils/
```

#### 유지 사항

- 기존 LMS 라우팅 구조는 `/lms` 접두사 하위에 그대로 보존
- LMS 전용 컴포넌트/훅은 `features/lms/` 내에 유지
- 테마/언어 컨텍스트는 공통 레이어로 승격

### 3.2 인증 가드

```tsx
// src/shared/components/AuthGuard.tsx
function AuthGuard({ children, requiredRole }: AuthGuardProps) {
  const { user, isLoading } = useAuth();
  const location = useLocation();

  if (isLoading) return <LoadingSpinner />;
  if (!user) return <Navigate to="/login" state={{ from: location }} replace />;
  if (requiredRole && user.role !== requiredRole) return <Navigate to="/" replace />;

  return children;
}
```

### 4.3 공통 컴포넌트

모든 공통 컴포넌트는 CSS 변수 기반으로 테마를 따르며, 다크 모드와 액센트 컬러를 자동 반영한다.

#### Button

```tsx
interface ButtonProps {
  variant: "primary" | "secondary" | "outline" | "ghost" | "danger";
  size: "sm" | "md" | "lg";
  isLoading?: boolean;
  leftIcon?: ReactNode;
  rightIcon?: ReactNode;
  fullWidth?: boolean;
}
```

#### Badge

```tsx
interface BadgeProps {
  variant: "default" | "success" | "warning" | "error" | "info";
  size: "sm" | "md";
}
```

#### Avatar

```tsx
interface AvatarProps {
  src?: string;
  name: string;          // 이미지 없을 시 이니셜 표시
  size: "xs" | "sm" | "md" | "lg" | "xl";
  status?: "online" | "offline" | "busy";
}
```

#### Tabs

```tsx
interface TabsProps {
  items: { key: string; label: string; content: ReactNode }[];
  defaultActiveKey?: string;
  variant: "line" | "enclosed" | "pill";
}
```

#### 기타 공통 컴포넌트

### 7.2 Nginx Rewrite 규칙

```nginx
# docker/nginx.conf

server {
    listen 80;
    server_name growai.co.kr;

    root /usr/share/nginx/html;
    index index.html;

    # gzip 압축
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types
        text/plain
        text/css
        text/javascript
        application/javascript
        application/json
        image/svg+xml;

    # 정적 파일 캐싱 (해시 기반이므로 장기 캐시 가능)
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # i18n 번역 파일 (짧은 캐시)
    location /locales/ {
        expires 1h;
        add_header Cache-Control "public";
    }

    # API 프록시 (백엔드로 전달)
    location /api/ {
        proxy_pass http://api:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 프록시 (VLS 화상 강의 등)
    location /ws/ {
        proxy_pass http://api:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }

    # SPA 폴백: 모든 경로를 index.html로
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 보안 헤더
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
}
```

WORKDIR /app

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
