## 2. 서비스별 상세 정의

---

### 2.1 MAP — Manufacturing AI Platform

**서비스 개요**

제조 현장의 생산 공정 데이터를 실시간으로 수집하고 AI 기반 분석을 통해 품질 예측, 설비 예지 보전, 공정 최적화를 수행하는 플랫폼이다. 센서 데이터와 MES 연동을 기반으로 불량률 감소 및 생산성 향상을 실현하며, 현장 작업자부터 경영진까지 계층별 맞춤 대시보드를 제공한다.

**핵심 기능**

- 실시간 공정 모니터링: IoT 센서 데이터 수집 및 시각화, 이상 징후 즉시 알림
- 품질 예측 모델: 생산 조건 변화에 따른 불량 발생 확률 사전 예측
- 설비 예지 보전: 설비 고장 패턴 학습을 통한 유지보수 시점 최적화
- 공정 파라미터 최적화: AI 기반 최적 공정 조건 자동 추천
- 생산 리포트 자동화: 일간/주간/월간 생산 실적 보고서 자동 생성

**대상 사용자**

- 현장 작업자 (실시간 공정 상태 확인)
- 품질 관리자 (불량 분석 및 예측)
- 설비 관리자 (예지 보전 일정 관리)
- 공장장 / 경영진 (KPI 대시보드)

**기술 스택**

- Backend: FastAPI + TimescaleDB (시계열 데이터)
- AI/ML: TensorFlow, scikit-learn, 이상 탐지 모델
- 데이터 수집: Apache Kafka + MQTT 브로커
- 시각화: Grafana 임베디드 대시보드
- 인프라: GCP Cloud Run + BigQuery

**구현 우선순위: Phase 2**

Phase 1에서 LMS/VLS 기반 교육 인프라가 안정화된 이후, 제조 현장 AI 적용을 본격적으로 추진한다. 센서 연동과 데이터 파이프라인 구축에 별도 현장 작업이 필요하므로 Phase 2에 배치한다.

**LearnForm 연동 포인트**

- MAP에서 수집된 공정 데이터를 기반으로 LearnForm이 현장 맞춤 교육 콘텐츠 자동 생성
- 불량 발생 시 관련 표준작업절차(SOP) 교육을 자동 추천
- 작업자별 역량 평가 결과를 MAP 권한 등급과 연계

### 2.2 LMS — Learning Management System

**서비스 개요**

조직 내 교육 과정의 설계, 배포, 수강, 평가, 이수 관리를 통합 운영하는 학습 관리 시스템이다. CREATOR 7단계 방법론에 기반하여 체계적인 교육 설계를 지원하고, FKDS 순환 모델을 통해 학습자 참여를 극대화한다. 관리자 대시보드를 통해 조직 전체의 교육 현황을 한눈에 파악할 수 있다.

**핵심 기능**

- 과정 관리: 교육 과정 등록, 카테고리 분류, 수강 기간 설정, 이수 조건 관리
- 학습자 관리: 수강 신청/승인, 학습 진도 추적, 이수 현황 통계
- 평가 시스템: 퀴즈, 과제, 시험 출제 및 자동 채점, 역량 기반 평가
- 수료증 발급: 이수 기준 충족 시 수료증 자동 발급 및 관리
- 교육 분석: 과정별/부서별/개인별 학습 데이터 분석 리포트

**대상 사용자**

- 학습자 (수강 및 평가 참여)
- 교육 운영자 (과정 관리 및 학습자 관리)
- 교육 설계자 (커리큘럼 설계)
- 인사 관리자 (역량 평가 연계)

**기술 스택**

- Frontend: Next.js 14 App Router + Tailwind CSS + TypeScript
- Backend: FastAPI + SQLAlchemy 2.0 + Pydantic v2
- DB: AlloyDB (PostgreSQL 호환)
- 캐시: Redis (Memorystore)
- 인프라: GCP Cloud Run

**구현 우선순위: Phase 1**

GrowAI 플랫폼의 핵심 서비스로, 모든 교육 관련 서비스의 기반이 된다. 사용자 관리, 과정 관리, 학습 이력 관리 등 공통 데이터 모델을 최우선으로 구축한다.

**LearnForm 연동 포인트**

- LearnForm CREATOR 파이프라인에서 생성된 콘텐츠가 LMS에 자동 등록
- LMS 학습 데이터가 LearnForm의 콘텐츠 최적화(CREATOR O단계)에 피드백
- LMS 역량 평가 결과를 기반으로 LearnForm이 맞춤 보충 학습 콘텐츠 생성

### 2.3 VLS — Video Lecture System

**서비스 개요**

실시간 화상 강의와 녹화 강의를 통합 지원하는 영상 강의 시스템이다. 라이브 스트리밍, 화면 공유, 채팅, Q&A, 출석 체크 등 온라인 강의에 필요한 모든 기능을 제공한다. CDN과 연계하여 대규모 동시 접속 환경에서도 안정적인 영상 전송을 보장한다.

**핵심 기능**

- 라이브 스트리밍: WebRTC 기반 실시간 양방향 화상 강의
- VOD 관리: 녹화 강의 업로드, 인코딩, 스트리밍 제공
- 인터랙션: 실시간 채팅, 투표, Q&A 게시판, 손들기 기능
- 출석 관리: 자동 출석 체크, 학습 시간 기록, 중도 이탈 감지
- 화면 공유 및 화이트보드: 강사 화면 공유와 실시간 드로잉 도구

**대상 사용자**

- 강사 (강의 진행 및 콘텐츠 제공)
- 학습자 (실시간/VOD 수강)
- 교육 운영자 (일정 관리 및 출석 관리)

**기술 스택**

- Frontend: Next.js 14 + WebRTC + HLS.js
- Backend: FastAPI + WebSocket (실시간 통신)
- 미디어 서버: Janus / LiveKit
- 인코딩: FFmpeg + GCP Transcoder API
- 스토리지: GCS (원본 및 인코딩 파일)
- 인프라: GCP Cloud Run + CDN 연계

**구현 우선순위: Phase 1**

영상 기반 교육은 이러닝의 핵심 전달 매체이며, LMS와 동시에 구축되어야 한다. VAS(영상 자동 요약)의 입력 데이터를 제공하는 선행 서비스이기도 하다.

**LearnForm 연동 포인트**

- LearnForm CREATOR A단계(산출물생성)에서 생성된 대본으로 VLS 강의 자동 구성
- VLS 강의 영상이 VAS로 전달되어 요약 콘텐츠 자동 생성
- 학습자 영상 시청 패턴 데이터를 LearnForm 콘텐츠 최적화에 활용

### 2.4 VAS — Video Auto Summary

**서비스 개요**

강의 영상을 AI가 자동으로 분석하여 텍스트 요약, 핵심 키워드 추출, 챕터 분할, 자막 생성을 수행하는 서비스이다. 장시간 강의 영상의 핵심 내용을 빠르게 파악할 수 있도록 지원하여 학습 효율을 극대화한다. 다국어 자막 생성을 통해 글로벌 교육 환경도 지원한다.

**핵심 기능**

- 자동 텍스트 요약: 영상 음성을 텍스트로 변환(STT) 후 핵심 내용 요약
- 챕터 자동 분할: 내용 전환 지점을 감지하여 영상을 논리적 단위로 분할
- 키워드 추출: 강의 핵심 용어 및 개념 자동 추출, 용어 사전 연계
- 다국어 자막 생성: 한국어 원본 기반 영/중/일 자막 자동 번역 및 타임코드 동기화
- 하이라이트 클립: 중요 구간 자동 편집 및 숏폼 콘텐츠 생성

**대상 사용자**

- 학습자 (요약 콘텐츠로 효율적 학습)
- 콘텐츠 제작자 (자막 및 요약 자동화로 작업 시간 절감)
- 교육 운영자 (강의 품질 분석)

**기술 스택**

- AI/ML: Whisper (STT) + GPT-4o (요약) + Claude 3.5 Sonnet (분석)
- 영상 처리: FFmpeg + OpenCV
- Backend: FastAPI + Celery (비동기 처리)
- 큐: Redis (작업 큐 관리)
- 스토리지: GCS (영상 원본 및 처리 결과)
- 인프라: GCP Cloud Run + Vertex AI

**구현 우선순위: Phase 2**

VLS에서 영상 콘텐츠가 축적된 이후 본격 가동한다. STT 및 요약 AI 모델의 정확도 검증이 선행되어야 하며, Phase 1 인프라 위에서 비동기 처리 파이프라인을 구축한다.

**LearnForm 연동 포인트**

- VAS 요약 결과를 LearnForm CREATOR E단계(경험설계)의 학습 자료로 활용
- LearnForm이 VAS 요약 기반으로 퀴즈/평가 문항 자동 생성
- VAS 키워드 데이터를 LearnForm 콘텐츠 추천 알고리즘에 반영

### 2.5 CCB — Customer Care Bot

**서비스 개요**

AI 기반 다국어 고객 상담 챗봇으로, 24시간 무중단 고객 지원을 제공한다. RAG(Retrieval-Augmented Generation) 기술을 활용하여 기업별 지식 베이스에 기반한 정확한 답변을 생성하며, 복잡한 문의는 상담원에게 자동 에스컬레이션한다. 채팅, 이메일, 전화 등 옴니채널을 통합 지원한다.

**핵심 기능**

- 다국어 자동 응답: 한/영/중/일 4개 언어 실시간 자동 번역 및 응답
- RAG 기반 지식 검색: 기업 매뉴얼, FAQ, 정책 문서 기반 정확한 답변 생성
- 상담원 에스컬레이션: AI 판단 기준에 따라 복잡/민감 문의를 인간 상담원에게 전달
- 감성 분석: 고객 감정 상태 실시간 분석, 부정적 감정 감지 시 우선 대응
- 상담 이력 관리: 고객별 상담 히스토리 통합 관리 및 패턴 분석

**대상 사용자**

- 외부 고객 (제품/서비스 문의)
- 내부 직원 (사내 IT/HR 지원)
- 상담 관리자 (상담 품질 모니터링)
- 서비스 기획자 (고객 인사이트 분석)

**기술 스택**

- AI: LangChain + LangGraph + GPT-4o (대화 생성)
- RAG: 벡터DB(Pinecone/Weaviate) + 임베딩 모델
- Backend: FastAPI + WebSocket (실시간 채팅)
- 채널 통합: Twilio (전화/SMS), SendGrid (이메일)
- 인프라: GCP Cloud Run + Memorystore (세션 관리)

**구현 우선순위: Phase 3**

LMS/VLS 서비스의 사용자 기반이 확보된 이후 고객 지원 자동화를 추진한다. RAG용 지식 베이스 구축과 다국어 모델 튜닝에 충분한 준비 기간이 필요하다.

**LearnForm 연동 포인트**

- CCB에서 자주 묻는 질문 패턴을 분석하여 LearnForm이 관련 교육 콘텐츠 자동 생성
- LearnForm 학습 콘텐츠를 CCB 지식 베이스에 자동 등록
- 고객 문의 트렌드를 교육 과정 기획에 반영 (CREATOR C단계 입력)

### 2.6 CCS — Claude Code Skill

**서비스 개요**

Anthropic Claude Code의 스킬(Skill) 시스템을 활용하여 개발팀의 생산성을 극대화하는 서비스이다. 코드 생성, 리뷰, 리팩토링, 테스트 작성, 문서화 등 개발 워크플로우 전반에 AI 어시스턴트를 통합한다. GrowAI 플랫폼 전체의 개발 표준과 아키텍처 패턴을 학습한 맞춤형 개발 도구를 제공한다.

**핵심 기능**

- 코드 생성 및 리뷰: 프로젝트 컨벤션에 맞는 코드 자동 생성 및 품질 검사
- 커스텀 스킬: GrowAI 도메인에 특화된 Claude Code 스킬 라이브러리
- CI/CD 통합: PR 리뷰 자동화, 테스트 커버리지 분석, 배포 파이프라인 지원
- 아키텍처 가이드: 프로젝트 구조 및 설계 패턴 자동 추천
- 지식 관리: 코드베이스 문서 자동 생성 및 업데이트

**대상 사용자**

- 개발자 (일상 개발 업무)
- 테크 리드 (코드 리뷰 및 아키텍처 의사결정)
- DevOps 엔지니어 (인프라 코드 관리)
- 신규 입사자 (온보딩 가속)

**기술 스택**

- AI: Claude Code CLI + Claude API (Anthropic SDK)
- 스킬 정의: CLAUDE.md + 커스텀 스킬 YAML/JSON
- CI/CD: GitHub Actions + Cloud Build
- 코드 분석: ruff, mypy, ESLint, TypeScript strict
- 인프라: 로컬 개발 환경 + GCP Cloud Build

**구현 우선순위: Phase 1**

개발팀의 생산성에 직접적인 영향을 미치므로 최우선 구축한다. 다른 서비스의 개발 속도를 높이는 메타 서비스로서, Phase 1에서 조기 도입하여 전체 프로젝트 일정을 단축한다.

**LearnForm 연동 포인트**

- CCS에서 축적된 개발 패턴을 LearnForm 개발자 교육 콘텐츠로 자동 변환
- LearnForm 코드 실습 과제의 자동 채점에 CCS 분석 엔진 활용
- 신규 개발자 온보딩 교육을 LearnForm + CCS 통합 환경으로 제공

### 2.7 CDN — Content Delivery Network

**서비스 개요**

GrowAI 플랫폼의 모든 미디어 콘텐츠(영상, 이미지, 문서)를 전 세계 엣지 노드를 통해 빠르고 안정적으로 전송하는 콘텐츠 전송 네트워크이다. 적응형 비트레이트 스트리밍(ABR)을 지원하여 네트워크 환경에 따라 최적의 품질을 자동 선택하며, DRM을 통해 콘텐츠 저작권을 보호한다.

**핵심 기능**

- 글로벌 엣지 배포: 아시아-태평양, 북미, 유럽 주요 거점 PoP(Point of Presence) 운영
- 적응형 스트리밍: HLS/DASH 기반 ABR 스트리밍으로 네트워크 상태 적응
- 콘텐츠 보호: DRM(Widevine, FairPlay) 적용 및 토큰 기반 접근 제어
- 자동 인코딩: 업로드 시 다중 해상도(360p~4K) 자동 트랜스코딩
- 캐시 최적화: 콘텐츠 유형별 TTL 관리, 캐시 무효화 API 제공

**대상 사용자**

- 전체 GrowAI 서비스 (인프라 레이어)
- 콘텐츠 관리자 (업로드 및 배포 관리)
- 시스템 운영자 (성능 모니터링)

**기술 스택**

- CDN: GCP Cloud CDN + Media CDN
- 스토리지: GCS (멀티 리전)
- 인코딩: GCP Transcoder API + FFmpeg
- DRM: Widevine + FairPlay Streaming
- 모니터링: Cloud Monitoring + 커스텀 대시보드
- 인프라: GCP 글로벌 로드밸런서

**구현 우선순위: Phase 1**

VLS, LMS 등 미디어 기반 서비스의 필수 인프라이므로 Phase 1에서 함께 구축한다. GCP의 관리형 서비스를 최대한 활용하여 초기 구축 부담을 최소화한다.

**LearnForm 연동 포인트**

- LearnForm CREATOR A단계에서 생성된 미디어 산출물의 CDN 자동 배포
- 학습자 접속 지역별 CDN 성능 데이터를 콘텐츠 배포 전략에 반영
- LearnForm 콘텐츠 버전 관리와 CDN 캐시 무효화 연동

### 2.8 CMS — Construction Management System

**서비스 개요**

건설 현장의 공정 관리, 안전 관리, 자재 관리, 인력 관리를 통합하는 스마트 건설 관리 시스템이다. 드론 촬영, IoT 센서, BIM(Building Information Modeling) 데이터를 AI로 분석하여 공정 지연 예측, 안전 위험 감지, 자재 최적 발주를 지원한다. 현장과 본사 간 실시간 정보 공유로 의사결정 속도를 높인다.

**핵심 기능**

- 공정 관리: BIM 연동 4D 공정표, 공정률 자동 산출, 지연 예측 알림
- 안전 관리: CCTV/IoT 기반 위험 행동 감지, 안전 점검 체크리스트 디지털화
- 자재 관리: 자재 입출고 실시간 추적, AI 기반 자재 소요량 예측 및 발주 최적화
- 인력 관리: 출퇴근 기록, 자격증 유효기간 관리, 작업 배치 최적화
- 현장 리포트: 일일 작업 보고서 자동 생성, 사진 기반 진척도 AI 분석

**대상 사용자**

- 현장 소장 (전체 현장 관리)
- 공정 관리자 (공정 계획 및 추적)
- 안전 관리자 (안전 점검 및 사고 예방)
- 자재 관리자 (자재 입출고 관리)
- 본사 PM (다중 현장 통합 관리)

**기술 스택**

- Frontend: Next.js 14 + Three.js (BIM 3D 뷰어)
- Backend: FastAPI + SQLAlchemy 2.0
- AI: 컴퓨터 비전 (안전 감지), 시계열 예측 (공정 분석)
- IoT: MQTT + Apache Kafka (센서 데이터)
- 스토리지: GCS (드론 영상, BIM 파일)
- 인프라: GCP Cloud Run + Vertex AI

**구현 우선순위: Phase 4**

도메인 전문성이 가장 높은 서비스로, 건설 업계 파트너십과 현장 검증이 필수적이다. Phase 1-3에서 확보한 AI/인프라 역량을 기반으로 Phase 4에서 본격 진입한다.

**LearnForm 연동 포인트**

- CMS 안전 교육 이수 데이터와 현장 출입 자격 연동
- LearnForm이 CMS 사고 사례를 기반으로 안전 교육 콘텐츠 자동 생성
- 현장 작업자 직무 역량 평가 결과를 LearnForm 맞춤 교육에 반영

## 3. 브랜드 통합 전략

### 3.1 GrowAI 아이덴티티 공유

모든 TLA 서비스는 GrowAI라는 단일 브랜드 아래 통합 운영된다.

- **통합 로고 시스템**: GrowAI 메인 로고 + 서비스별 TLA 서브 마크 (예: GrowAI | LMS)
- **컬러 시스템**: GrowAI 기본 컬러 팔레트를 공유하되, 서비스별 액센트 컬러로 구분
  - LMS: 블루 계열 (신뢰, 교육)
  - VLS: 퍼플 계열 (창의, 영상)
  - MAP: 그린 계열 (제조, 성장)
  - CCB: 오렌지 계열 (소통, 따뜻함)
  - CCS: 다크 계열 (개발, 기술)
  - CDN: 시안 계열 (속도, 네트워크)
  - VAS: 핑크 계열 (효율, 요약)
  - CMS: 앰버 계열 (건설, 현장)
- **타이포그래피**: Pretendard (한글) + Inter (영문) 통일
- **아이콘 체계**: Lucide 아이콘 세트 기반 커스텀 아이콘 라이브러리

### 3.2 통합 UX 원칙

- 서비스 간 일관된 네비게이션 구조 (GNB에서 서비스 전환)
- 동일한 인터랙션 패턴 (버튼, 폼, 모달, 토스트 등)
- 반응형 디자인 가이드라인 통일 (모바일/태블릿/데스크톱)
- 접근성 WCAG 2.1 AA 기준 준수

## 4. 공통 인프라

### 4.1 통합 인증 (Authentication & Authorization)

| 구성 요소 | 기술 | 설명 |
|----------|------|------|
| SSO | GCP Identity Platform | 전 서비스 단일 로그인 |
| OAuth 2.0 | Google, Microsoft 연동 | 소셜/기업 계정 로그인 |
| RBAC | 커스텀 권한 엔진 | 서비스별 역할 기반 접근 제어 |
| API 인증 | JWT + API Key | 서비스 간 통신 인증 |
| 세션 관리 | Redis (Memorystore) | 분산 세션 저장소 |

### 4.2 테마 시스템

- **라이트/다크 모드**: 전 서비스 일괄 적용, 사용자 설정 동기화
- **기업 커스텀 테마**: B2B 고객사별 로고, 컬러, 도메인 커스터마이징
- **CSS 변수 기반**: `--grow-primary`, `--grow-secondary` 등 통합 디자인 토큰

### 4.3 다국어 (i18n)

- **지원 언어**: 한국어(기본), 영어, 중국어(간체), 일본어
- **번역 관리**: i18next 기반 통합 번역 키 관리
- **동적 번역**: AI 기반 콘텐츠 실시간 번역 (CCB, VAS 연계)
- **로케일 관리**: 날짜, 숫자, 통화 형식 자동 적용

### 4.4 알림 시스템

| 채널 | 기술 | 용도 |
|------|------|------|
| 인앱 알림 | WebSocket + SSE | 실시간 알림 (과제 마감, 공정 이상 등) |
| 이메일 | SendGrid | 공지사항, 수료증, 주간 리포트 |
| 푸시 알림 | Firebase Cloud Messaging | 모바일 앱 알림 |
| SMS | Twilio | 긴급 알림 (안전 경보, 시스템 장애) |
| Slack/Teams | Webhook | 개발팀 및 관리자 알림 |

### 5.3 데이터 동기화 방식

- **이벤트 기반 (Event-Driven)**: GCP Pub/Sub를 통한 비동기 이벤트 전파
- **API 게이트웨이**: 서비스 간 동기 호출 시 통합 API 게이트웨이 경유
- **데이터 레이크**: BigQuery 기반 통합 분석 데이터 저장소
- **CDC (Change Data Capture)**: Debezium을 통한 DB 변경분 실시간 캡처

## 6. Phase별 구현 로드맵

### Phase 1 — 핵심 기반 (Month 1-6)

- LMS: 과정 관리, 학습자 관리, 기본 평가
- VLS: VOD 스트리밍, 기본 라이브 강의
- CDN: GCP Media CDN 기반 미디어 전송
- CCS: Claude Code 스킬 기본 세트 구축
- 공통 인프라: 인증, 테마, 다국어 기본 구조

### Phase 2 — 확장 (Month 7-12)

- MAP: 센서 데이터 수집, 기본 모니터링 대시보드
- VAS: STT + 자동 요약 MVP
- LMS 고도화: 역량 평가, 수료증 자동 발급
- VLS 고도화: 인터랙션 기능 강화

### Phase 3 — 지능화 (Month 13-18)

- CCB: RAG 기반 상담 봇 MVP, 한/영 2개 언어
- MAP 고도화: 예지 보전, 품질 예측 모델
- VAS 고도화: 다국어 자막, 하이라이트 클립
- 전체 서비스 LearnForm 연동 고도화

### Phase 4 — 도메인 확장 (Month 19-24)

- CMS: 건설 현장 관리 MVP
- CCB 고도화: 4개 언어, 옴니채널
- 전체 서비스 데이터 메시 완성
- 글로벌 CDN 확장
