## A. 용어 사전 (가나다순)

> 모든 용어를 **한글 뜻 / 쉬운 비유 / NEWKL에서의 활용** 세 가지 관점으로 설명합니다.

---

### ㄱ

#### Go (고)
- **한글 뜻**: 구글이 만든 정적 타입 프로그래밍 언어
- **쉬운 비유**: 빠르고 가벼운 단거리 육상 선수. 복잡한 기능보다 빠른 실행과 동시 처리에 특화되어 있다.
- **NEWKL 활용**: Orchestrator(오케스트레이터) 서비스 개발에 사용. 마이크로서비스 간 통신을 빠르게 처리한다.

#### GPU (Graphics Processing Unit)
- **한글 뜻**: 그래픽 처리 장치. 대량의 병렬 연산에 특화된 프로세서.
- **쉬운 비유**: 한 명의 천재(CPU)가 문제를 하나씩 풀 때, GPU는 수천 명의 학생이 동시에 시험을 치르는 것과 같다.
- **NEWKL 활용**: AI 모델 추론(LLM, Veo 등)에 GPU를 사용하여 빠른 콘텐츠 생성을 지원한다.

#### GraphQL (그래프QL)
- **한글 뜻**: API를 위한 쿼리 언어. 클라이언트가 필요한 데이터만 요청할 수 있다.
- **쉬운 비유**: 뷔페에서 원하는 음식만 골라 담는 것. REST가 "오늘의 정식"이라면, GraphQL은 "자유 뷔페"이다.
- **NEWKL 활용**: 프론트엔드에서 복잡한 학습 데이터 조회 시 필요한 필드만 가져오는 데 활용 가능하다.

#### gRPC
- **한글 뜻**: 구글이 만든 고성능 원격 프로시저 호출(RPC) 프레임워크
- **쉬운 비유**: 전화 통화처럼 서버와 서버가 직접 대화하는 방식. REST가 편지(텍스트)를 주고받는다면, gRPC는 전화(바이너리)를 거는 것이다.
- **NEWKL 활용**: Go Orchestrator와 백엔드 마이크로서비스 간 내부 통신에 사용하여 지연 시간을 최소화한다.

#### Git (깃)
- **한글 뜻**: 분산 버전 관리 시스템
- **쉬운 비유**: 문서 작성할 때 "최종.docx", "진짜최종.docx"를 만드는 대신, 모든 변경 이력을 자동으로 기록해 주는 타임머신.
- **NEWKL 활용**: 모든 소스 코드의 버전 관리. GitHub를 통한 협업과 코드 리뷰에 필수적이다.

### ㄴ

#### NestJS (네스트JS)
- **한글 뜻**: Node.js 기반의 서버 사이드 프레임워크. Angular에서 영감을 받은 구조화된 아키텍처 제공.
- **쉬운 비유**: 레고 블록처럼 모듈을 조립해서 서버를 만드는 방식. 설계도(데코레이터)를 따라가면 자연스럽게 깔끔한 구조가 완성된다.
- **NEWKL 활용**: BFF(Backend-for-Frontend) 계층 구현에 사용. 프론트엔드와 백엔드 사이에서 데이터를 가공하고 전달한다.

#### Next.js (넥스트JS)
- **한글 뜻**: React 기반의 풀스택 웹 프레임워크. SSR, SSG, ISR 등 다양한 렌더링 전략 지원.
- **쉬운 비유**: React가 엔진이라면 Next.js는 완성된 자동차. 엔진만으로는 달릴 수 없지만, 자동차(Next.js)에 태우면 바로 도로를 달릴 수 있다.
- **NEWKL 활용**: 모든 프론트엔드 서비스(LearnForm, LearnBridge 등)의 핵심 프레임워크로 사용한다.

#### Node.js (노드JS)
- **한글 뜻**: 브라우저 밖에서 JavaScript를 실행할 수 있게 해주는 런타임 환경
- **쉬운 비유**: JavaScript가 원래 브라우저(집) 안에서만 살 수 있었는데, Node.js가 바깥 세상(서버)에서도 살 수 있게 해준 여권.
- **NEWKL 활용**: 프론트엔드 빌드, BFF 서버 실행 등 JavaScript/TypeScript 기반 서비스의 실행 환경이다.

### ㄷ

#### Docker (도커)
- **한글 뜻**: 애플리케이션을 컨테이너로 패키징하여 어디서든 동일하게 실행할 수 있게 하는 플랫폼
- **쉬운 비유**: 이삿짐을 컨테이너 박스에 담아 어디로든 옮기면 그대로 꺼내 쓸 수 있는 것. "내 컴퓨터에서는 되는데?"를 없애 준다.
- **NEWKL 활용**: 모든 서비스를 Docker 컨테이너로 패키징하여 GCP Cloud Run에 배포한다.

### ㄹ

#### React (리액트)
- **한글 뜻**: 사용자 인터페이스를 만들기 위한 JavaScript 라이브러리. 컴포넌트 기반 개발 방식.
- **쉬운 비유**: 레고 블록처럼 작은 UI 조각(컴포넌트)을 만들고, 이를 조합해서 화면을 완성하는 것.
- **NEWKL 활용**: Next.js의 기반 라이브러리로, 모든 화면의 UI 컴포넌트를 React로 구현한다.

#### Redis (레디스)
- **한글 뜻**: 인메모리 데이터 저장소. 캐시, 메시지 브로커, 세션 저장소로 활용.
- **쉬운 비유**: 책상 위의 포스트잇. 자주 찾는 정보를 서랍(DB) 대신 눈앞(메모리)에 붙여 놓아 즉시 확인 가능.
- **NEWKL 활용**: Celery 작업 큐의 브로커, 세션 캐시, 실시간 데이터 임시 저장에 사용한다. GCP Memorystore로 운영.

#### REST (레스트)
- **한글 뜻**: Representational State Transfer. HTTP를 기반으로 자원을 주고받는 API 설계 방식.
- **쉬운 비유**: 식당 메뉴판. GET(메뉴 보기), POST(주문하기), PUT(주문 변경), DELETE(주문 취소)처럼 정해진 동작으로 소통한다.
- **NEWKL 활용**: 프론트엔드와 백엔드 간 데이터 통신의 기본 방식. FastAPI와 NestJS 모두 REST API를 제공한다.

#### RSC (React Server Components)
- **한글 뜻**: 서버에서 실행되는 React 컴포넌트. 클라이언트에 JavaScript를 보내지 않아 성능이 좋다.
- **쉬운 비유**: 레스토랑에서 요리를 완성해서 내보내는 것(서버 컴포넌트) vs. 테이블에서 직접 구워 먹는 것(클라이언트 컴포넌트).
- **NEWKL 활용**: Next.js App Router에서 데이터 페칭이 필요한 페이지를 서버 컴포넌트로 구현하여 초기 로딩 속도를 개선한다.

### ㅁ

#### MCP (Model Context Protocol)
- **한글 뜻**: AI 모델이 외부 도구와 데이터에 접근할 수 있게 해주는 표준 프로토콜
- **쉬운 비유**: AI에게 손과 발을 달아주는 규격. 이 규격을 따르면 어떤 도구든 AI가 사용할 수 있게 된다.
- **NEWKL 활용**: AI 에이전트가 외부 서비스(DB, 파일 시스템, API 등)와 상호작용할 때 MCP를 통해 안전하게 접근한다.

#### Microservice (마이크로서비스)
- **한글 뜻**: 하나의 큰 애플리케이션을 작은 독립적 서비스들로 나누는 아키텍처 패턴
- **쉬운 비유**: 대형 백화점 대신 전문 매장 거리. 각 매장(서비스)이 독립적으로 운영되지만, 함께 하나의 상권(플랫폼)을 형성한다.
- **NEWKL 활용**: TLA 플랫폼의 9개 서비스가 각각 독립적으로 개발, 배포, 확장된다.

### ㅂ

#### Vector DB (벡터 데이터베이스)
- **한글 뜻**: 텍스트나 이미지를 숫자 벡터로 변환하여 저장하고 유사도 검색을 수행하는 데이터베이스
- **쉬운 비유**: 도서관에서 제목이 아닌 "내용이 비슷한 책"을 찾아주는 사서. 의미적 유사성으로 검색한다.
- **NEWKL 활용**: RAG 시스템에서 학습 콘텐츠를 벡터화하여 저장하고, 사용자 질문과 가장 관련 있는 자료를 검색한다.

#### Veo (비오)
- **한글 뜻**: 구글 딥마인드의 AI 비디오 생성 모델
- **쉬운 비유**: 텍스트 설명만 주면 영상을 만들어 주는 AI 감독.
- **NEWKL 활용**: LearnForm에서 학습 영상 콘텐츠를 자동 생성하는 데 활용한다.

#### Vertex AI
- **한글 뜻**: 구글 클라우드의 통합 AI/ML 플랫폼
- **쉬운 비유**: AI 모델을 훈련하고, 배포하고, 관리하는 원스톱 공장.
- **NEWKL 활용**: Gemini 모델 호출, 임베딩 생성, AI 파이프라인 관리에 사용한다.

#### Vite (비트)
- **한글 뜻**: 차세대 프론트엔드 빌드 도구. 빠른 개발 서버와 번들링 제공.
- **쉬운 비유**: 기존 빌드 도구가 모든 재료를 한꺼번에 요리한다면, Vite는 주문이 들어올 때마다 즉석 요리를 해서 빠르다.
- **NEWKL 활용**: Vitest 등 테스트 도구의 기반으로 활용된다.

#### VRAM (Video RAM)
- **한글 뜻**: GPU 전용 메모리. AI 모델 로딩과 연산에 사용.
- **쉬운 비유**: GPU의 작업 책상 크기. VRAM이 클수록 더 큰 AI 모델을 올려놓고 작업할 수 있다.
- **NEWKL 활용**: AI 모델 추론 시 필요한 VRAM 용량을 고려하여 GPU 인스턴스(L4 등)를 선택한다.

### ㅅ

#### SPA (Single Page Application)
- **한글 뜻**: 단일 페이지 애플리케이션. 하나의 HTML 페이지에서 동적으로 콘텐츠를 교체하는 방식.
- **쉬운 비유**: 한 장의 종이 위에서 내용만 계속 지우고 새로 쓰는 것. 페이지 전체를 새로 가져오지 않는다.
- **NEWKL 활용**: Next.js의 클라이언트 측 네비게이션이 SPA처럼 동작하여 부드러운 화면 전환을 제공한다.

#### SQL (Structured Query Language)
- **한글 뜻**: 구조화된 질의 언어. 관계형 데이터베이스를 조작하기 위한 표준 언어.
- **쉬운 비유**: 데이터베이스에 말을 거는 언어. "이 조건에 맞는 데이터를 가져와 줘"라고 요청하는 것.
- **NEWKL 활용**: PostgreSQL(AlloyDB)에 학습 데이터, 사용자 정보 등을 저장하고 조회하는 데 사용한다.

#### SSE (Server-Sent Events)
- **한글 뜻**: 서버가 클라이언트에 실시간으로 단방향 데이터를 전송하는 기술
- **쉬운 비유**: 라디오 방송. 방송국(서버)이 일방적으로 송출하고 청취자(클라이언트)는 듣기만 한다.
- **NEWKL 활용**: AI 콘텐츠 생성 진행 상황을 실시간으로 프론트엔드에 스트리밍할 때 사용한다.

#### SSG (Static Site Generation)
- **한글 뜻**: 빌드 시점에 HTML을 미리 생성해 두는 렌더링 방식
- **쉬운 비유**: 미리 인쇄해 둔 전단지. 요청이 올 때마다 인쇄하는 게 아니라 이미 만들어 둔 것을 배포한다.
- **NEWKL 활용**: 변경이 적은 페이지(소개 페이지, 도움말 등)를 빌드 시 미리 생성하여 빠르게 제공한다.

#### SSR (Server-Side Rendering)
- **한글 뜻**: 서버에서 HTML을 생성하여 클라이언트에 전달하는 렌더링 방식
- **쉬운 비유**: 레스토랑 주방에서 요리를 완성해서 내보내는 것. 손님(브라우저)은 완성된 요리(HTML)를 바로 받는다.
- **NEWKL 활용**: SEO가 중요한 페이지와 초기 로딩 속도가 중요한 대시보드 페이지에 SSR을 적용한다.

#### Streaming UI (스트리밍 UI)
- **한글 뜻**: 서버에서 생성되는 UI를 점진적으로 클라이언트에 전송하여 표시하는 기술
- **쉬운 비유**: 영화를 다운로드 완료 후 보는 것이 아니라, 버퍼링하면서 바로 재생하는 스트리밍.
- **NEWKL 활용**: AI가 생성하는 학습 콘텐츠를 실시간으로 화면에 표시하여 사용자 대기 시간을 줄인다.

#### Supabase (수파베이스)
- **한글 뜻**: 오픈소스 Firebase 대안. PostgreSQL 기반의 BaaS(Backend as a Service).
- **쉬운 비유**: 개발자를 위한 올인원 백엔드 키트. 데이터베이스, 인증, 스토리지를 한 곳에서 제공한다.
- **NEWKL 활용**: 인증(Auth), 실시간 데이터 동기화, 스토리지 관리 등에 활용 가능한 백엔드 서비스이다.

#### SWC
- **한글 뜻**: Speedy Web Compiler. Rust로 작성된 초고속 JavaScript/TypeScript 컴파일러.
- **쉬운 비유**: JavaScript 코드를 번역하는 기존 통역사(Babel)보다 20배 빠른 AI 동시통역.
- **NEWKL 활용**: Next.js의 기본 컴파일러로 사용되어 빌드 속도를 크게 향상시킨다.

#### Shadcn UI
- **한글 뜻**: 복사-붙여넣기 방식의 React UI 컴포넌트 라이브러리. Tailwind CSS와 Radix UI 기반.
- **쉬운 비유**: 가구를 사는 게 아니라 설계도를 받아서 내 집에 맞게 직접 만드는 것. 코드를 프로젝트에 직접 넣어 자유롭게 수정 가능.
- **NEWKL 활용**: 모든 프론트엔드 서비스의 UI 컴포넌트를 Shadcn UI로 구성하여 일관된 디자인을 유지한다.

#### SEO (Search Engine Optimization)
- **한글 뜻**: 검색 엔진 최적화. 웹사이트가 검색 결과에서 상위에 노출되도록 하는 기법.
- **쉬운 비유**: 가게 간판을 잘 달고, 지도에 정확히 등록하는 것. 손님(검색 엔진)이 쉽게 찾을 수 있도록 정비하는 작업.
- **NEWKL 활용**: Next.js의 SSR/SSG/메타데이터 기능을 활용하여 학습 콘텐츠 페이지의 검색 노출을 최적화한다.

### ㅇ

#### API (Application Programming Interface)
- **한글 뜻**: 애플리케이션 프로그래밍 인터페이스. 소프트웨어 간 소통 규약.
- **쉬운 비유**: 식당의 메뉴판과 주문 시스템. 손님(클라이언트)이 메뉴판(API 문서)을 보고 주문(요청)하면, 주방(서버)에서 음식(응답)을 내보낸다.
- **NEWKL 활용**: FastAPI로 백엔드 API를 만들고, 프론트엔드(Next.js)에서 이 API를 호출하여 데이터를 주고받는다.

#### App Router (앱 라우터)
- **한글 뜻**: Next.js 13+에서 도입된 새로운 라우팅 시스템. 파일 시스템 기반의 라우팅.
- **쉬운 비유**: 건물의 층별 안내도. 폴더 구조가 곧 URL 경로가 된다. `/app/about/page.tsx` 파일이 `/about` 페이지가 된다.
- **NEWKL 활용**: 모든 프론트엔드 페이지의 라우팅을 App Router로 관리한다. 레이아웃, 로딩, 에러 처리를 파일 단위로 구성한다.

#### AVIF
- **한글 뜻**: AV1 기반의 차세대 이미지 포맷. JPEG/PNG보다 훨씬 작은 파일 크기.
- **쉬운 비유**: 같은 사진을 반값에 더 선명하게 저장할 수 있는 새로운 사진 포맷.
- **NEWKL 활용**: Next.js의 Image 컴포넌트에서 AVIF 포맷으로 자동 변환하여 이미지 로딩 속도를 개선한다.

#### ORM (Object-Relational Mapping)
- **한글 뜻**: 객체-관계 매핑. 프로그래밍 언어의 객체와 데이터베이스 테이블을 자동으로 연결해 주는 기술.
- **쉬운 비유**: SQL(외국어)을 모르더라도 한국어(Python 코드)로 데이터베이스와 대화할 수 있게 해주는 통역사.
- **NEWKL 활용**: SQLAlchemy 2.0을 ORM으로 사용하여 Python 코드로 데이터베이스를 조작한다.

#### Edge Computing (엣지 컴퓨팅)
- **한글 뜻**: 데이터를 중앙 서버가 아닌 사용자와 가까운 위치에서 처리하는 기술
- **쉬운 비유**: 본사 창고에서 배송하는 대신, 동네 편의점에서 바로 물건을 꺼내주는 것.
- **NEWKL 활용**: Next.js의 Edge Runtime과 CDN을 활용하여 전 세계 사용자에게 빠르게 콘텐츠를 제공한다.

#### ESM (ECMAScript Modules)
- **한글 뜻**: JavaScript의 표준 모듈 시스템. import/export 문법 사용.
- **쉬운 비유**: 필요한 도구만 골라서 가져오는 도구 상자. 도구 상자 전체를 가져오지 않고 드라이버(import)만 꺼내 쓴다.
- **NEWKL 활용**: 모든 프론트엔드 코드와 Node.js 서비스에서 ESM 방식으로 모듈을 관리한다.

#### ISR (Incremental Static Regeneration)
- **한글 뜻**: 증분 정적 재생성. 빌드 후에도 특정 페이지만 백그라운드에서 다시 생성할 수 있는 기술.
- **쉬운 비유**: 전단지 전체를 다시 인쇄하지 않고, 변경된 페이지만 교체하는 것.
- **NEWKL 활용**: 학습 콘텐츠 목록 등 자주 변경되지만 즉시 반영이 필수는 아닌 페이지에 ISR을 적용한다.

#### i18n (Internationalization)
- **한글 뜻**: 국제화. 소프트웨어를 여러 언어와 지역에 맞게 적응시키는 과정.
- **쉬운 비유**: 한 권의 책을 여러 언어로 번역할 수 있도록 미리 구조를 잡아 두는 것.
- **NEWKL 활용**: 한국어/영어/일본어 등 다국어 지원을 위해 next-intl 등의 i18n 라이브러리를 사용한다.

### ㅈ

#### JSON (JavaScript Object Notation)
- **한글 뜻**: 데이터를 주고받을 때 사용하는 경량 텍스트 형식
- **쉬운 비유**: 누구나 읽을 수 있는 표준 서식. `{"이름": "홍길동", "나이": 25}` 처럼 직관적이다.
- **NEWKL 활용**: API 요청/응답, 설정 파일, 데이터 저장 등 거의 모든 데이터 교환에 JSON을 사용한다.

#### JWT (JSON Web Token)
- **한글 뜻**: JSON 기반의 인증 토큰. 사용자 신원을 증명하는 디지털 신분증.
- **쉬운 비유**: 놀이공원 입장 팔찌. 한번 받으면 팔찌만 보여주고 각 놀이기구(API)를 자유롭게 탈 수 있다.
- **NEWKL 활용**: 사용자 로그인 후 JWT를 발급하여 API 요청 시 인증에 사용한다.

#### Zustand (주스탄드)
- **한글 뜻**: 경량 React 상태 관리 라이브러리
- **쉬운 비유**: 공용 메모장. 여러 컴포넌트가 같은 메모장을 보고 쓰면서 정보를 공유한다. Redux보다 훨씬 간단하다.
- **NEWKL 활용**: 프론트엔드의 글로벌 상태(로그인 정보, UI 상태 등)를 Zustand로 관리한다.

### ㅊ

#### CDN (Content Delivery Network)
- **한글 뜻**: 콘텐츠 전송 네트워크. 전 세계에 분산된 서버에 콘텐츠를 캐싱하여 빠르게 제공.
- **쉬운 비유**: 전국 곳곳에 분점을 두는 프랜차이즈. 고객이 어디 있든 가장 가까운 지점에서 서비스를 받는다.
- **NEWKL 활용**: 정적 자산(이미지, JS, CSS)을 CDN에 캐싱하여 글로벌 사용자에게 빠르게 전달한다.

#### CI/CD (Continuous Integration / Continuous Deployment)
- **한글 뜻**: 지속적 통합 / 지속적 배포. 코드 변경을 자동으로 테스트하고 배포하는 파이프라인.
- **쉬운 비유**: 자동차 공장의 컨베이어 벨트. 코드를 올리면 자동으로 검사(테스트) → 조립(빌드) → 출고(배포)가 진행된다.
- **NEWKL 활용**: GitHub Actions + Cloud Build를 통해 코드 푸시 시 자동으로 테스트, 빌드, Cloud Run 배포를 수행한다.

#### CLI (Command Line Interface)
- **한글 뜻**: 명령줄 인터페이스. 텍스트 명령어로 컴퓨터를 조작하는 방식.
- **쉬운 비유**: 마우스로 클릭하는 대신 키보드로 직접 명령을 내리는 것. 능숙해지면 훨씬 빠르다.
- **NEWKL 활용**: gcloud, docker, npm, git 등 개발 도구를 CLI로 조작한다.

#### Cloud Run (클라우드 런)
- **한글 뜻**: GCP의 서버리스 컨테이너 실행 서비스. 요청이 있을 때만 컨테이너를 실행하고 비용 청구.
- **쉬운 비유**: 콜택시. 손님이 있을 때만 운행하고, 손님이 없으면 대기(비용 0). 직접 차를 사서 유지하지 않아도 된다.
- **NEWKL 활용**: 모든 마이크로서비스(FastAPI, NestJS, Go)를 Cloud Run에 배포하여 자동 확장과 비용 최적화를 달성한다.

#### Container (컨테이너)
- **한글 뜻**: 애플리케이션과 실행 환경을 하나로 묶은 격리된 실행 단위
- **쉬운 비유**: 도시락 용기. 밥, 반찬, 숟가락을 한 통에 담으면 어디서든 바로 먹을 수 있다. 앱, 라이브러리, 설정을 한 통에 담는 것.
- **NEWKL 활용**: Docker 컨테이너에 서비스를 패키징하여 일관된 실행 환경을 보장한다.

#### CORS (Cross-Origin Resource Sharing)
- **한글 뜻**: 교차 출처 리소스 공유. 다른 도메인 간 자원을 안전하게 공유하기 위한 브라우저 보안 정책.
- **쉬운 비유**: 아파트 출입 통제. 같은 단지(도메인) 주민은 자유롭게 드나들지만, 외부인은 허가(CORS 설정)가 필요하다.
- **NEWKL 활용**: 프론트엔드(web)와 백엔드(api)가 다른 도메인일 때 CORS 설정을 통해 통신을 허용한다.

#### CREATOR
- **한글 뜻**: NEWKL의 7단계 콘텐츠 생성 프레임워크
- **쉬운 비유**: 요리의 레시피 7단계. C(컨셉 잡기) → R(경로 설계) → E(경험 설계) → A(산출물 생성) → T(변화 적용) → O(최적 운영) → R(성찰).
- **NEWKL 활용**: LearnForm의 AI 콘텐츠 생성 전 과정이 CREATOR 7단계를 따른다. 각 단계에서 Human-in-the-Loop 검증을 수행한다.

#### CSS (Cascading Style Sheets)
- **한글 뜻**: 웹 페이지의 디자인(색상, 배치, 폰트 등)을 정의하는 스타일 시트 언어
- **쉬운 비유**: 건물의 인테리어. HTML이 건물의 뼈대라면, CSS는 벽지, 바닥재, 가구 배치를 결정한다.
- **NEWKL 활용**: Tailwind CSS를 통해 유틸리티 클래스 기반으로 스타일을 적용한다.

### ㅋ

#### FKDS
- **한글 뜻**: NEWKL의 학습 순환 모델. Feeling(느끼기) → Knowing(알기) → Doing(하기) → Sharing(나누기).
- **쉬운 비유**: 요리 배우기의 4단계. 맛있는 음식을 먹어보고(F) → 레시피를 배우고(K) → 직접 만들어 보고(D) → 다른 사람에게 알려주기(S).
- **NEWKL 활용**: 학습 콘텐츠 설계의 기본 구조. 모든 학습 단계가 FKDS 순환을 따르도록 AI가 콘텐츠를 구성한다.

### ㅌ

#### Tailwind CSS (테일윈드 CSS)
- **한글 뜻**: 유틸리티 우선(Utility-First) CSS 프레임워크. 미리 정의된 클래스를 조합하여 스타일 적용.
- **쉬운 비유**: 레고 블록처럼 작은 스타일 조각(`text-red-500`, `p-4`)을 조합하여 디자인을 완성하는 것.
- **NEWKL 활용**: 모든 프론트엔드 서비스의 스타일링을 Tailwind CSS로 수행한다. Shadcn UI와 함께 사용한다.

#### TTFB (Time to First Byte)
- **한글 뜻**: 첫 번째 바이트까지의 시간. 브라우저가 서버에 요청을 보낸 후 첫 응답을 받기까지의 시간.
- **쉬운 비유**: 식당에서 주문 후 첫 번째 반찬이 나올 때까지 걸리는 시간.
- **NEWKL 활용**: SSR과 Edge Computing을 활용하여 TTFB를 최소화하고 사용자 체감 속도를 개선한다.

#### Turbopack (터보팩)
- **한글 뜻**: Vercel이 만든 차세대 JavaScript 번들러. Rust로 작성되어 Webpack보다 빠르다.
- **쉬운 비유**: 기존 택배(Webpack)가 트럭이었다면, Turbopack은 드론 배송. 속도가 비교할 수 없이 빠르다.
- **NEWKL 활용**: Next.js 개발 서버에서 Turbopack을 사용하여 핫 리로드(HMR) 속도를 크게 개선한다.

#### TypeScript (타입스크립트)
- **한글 뜻**: JavaScript에 타입 시스템을 추가한 프로그래밍 언어. Microsoft 개발.
- **쉬운 비유**: JavaScript에 안전벨트를 채운 것. 변수에 어떤 값이 들어갈 수 있는지 미리 정해서 실수를 줄여 준다.
- **NEWKL 활용**: 모든 프론트엔드와 BFF 코드를 TypeScript strict 모드로 작성한다.

### ㅍ

#### PPR (Partial Prerendering)
- **한글 뜻**: 부분 사전 렌더링. 하나의 페이지에서 정적 부분과 동적 부분을 동시에 처리하는 Next.js의 기술.
- **쉬운 비유**: 신문에서 헤드라인(정적)은 미리 인쇄하고, 속보(동적)만 나중에 끼워 넣는 것.
- **NEWKL 활용**: 대시보드의 레이아웃은 미리 렌더링하고, 실시간 데이터(학습 진행률 등)만 동적으로 로딩한다.

#### PWA (Progressive Web App)
- **한글 뜻**: 프로그레시브 웹 앱. 웹 기술로 만든 앱 스토어 없이 설치 가능한 애플리케이션.
- **쉬운 비유**: 앱 스토어에서 다운 받지 않아도 홈 화면에 추가하면 앱처럼 동작하는 웹사이트.
- **NEWKL 활용**: 학습자가 오프라인에서도 콘텐츠를 열람할 수 있도록 PWA 기능을 제공한다.

#### PostgreSQL (포스트그레SQL)
- **한글 뜻**: 오픈소스 관계형 데이터베이스. 확장성과 표준 준수에 강점.
- **쉬운 비유**: 대형 도서관의 체계적인 서가. 어떤 종류의 데이터든 깔끔하게 분류하고 보관하며, 복잡한 질문에도 정확히 답해 준다.
- **NEWKL 활용**: GCP AlloyDB(PostgreSQL 호환)에 모든 구조화된 데이터(사용자, 프로젝트, 학습 기록 등)를 저장한다.

#### FastAPI (패스트API)
- **한글 뜻**: Python 기반의 현대적 고성능 웹 API 프레임워크
- **쉬운 비유**: Python으로 API를 만드는 가장 빠른 방법. 타입 힌트를 쓰면 문서(Swagger)가 자동으로 만들어진다.
- **NEWKL 활용**: AI 서비스 백엔드의 핵심 프레임워크. LangChain/LangGraph 체인을 FastAPI 엔드포인트로 노출한다.

### ㅎ

#### HMR (Hot Module Replacement)
- **한글 뜻**: 핫 모듈 교체. 코드를 수정하면 전체 페이지를 새로고침하지 않고 변경 부분만 즉시 반영하는 기능.
- **쉬운 비유**: 자동차가 달리는 중에 타이어만 교체하는 것. 멈추지(새로고침) 않고 부품(모듈)만 바꾼다.
- **NEWKL 활용**: Next.js + Turbopack 개발 환경에서 HMR을 통해 코드 수정 결과를 즉시 확인한다.

#### HTTP/3
- **한글 뜻**: 최신 버전의 HTTP 프로토콜. QUIC(UDP 기반) 위에서 동작하여 더 빠른 연결과 전송 제공.
- **쉬운 비유**: 기존 도로(TCP)에 신호등이 많았다면, HTTP/3은 고속도로(QUIC)를 이용해 정체 없이 빠르게 달린다.
- **NEWKL 활용**: Cloud Run과 CDN에서 HTTP/3을 지원하여 전송 속도와 연결 안정성을 개선한다.

### ㄹ (영문 L)

#### L4 GPU
- **한글 뜻**: NVIDIA의 추론 최적화 GPU. AI 모델 추론에 특화된 비용 효율적 그래픽 카드.
- **쉬운 비유**: 대형 트럭(A100) 대신 배달에 최적화된 소형 밴. 추론(배달) 작업에는 오히려 더 효율적이다.
- **NEWKL 활용**: GCP에서 AI 모델 추론 시 L4 GPU를 사용하여 비용 대비 최적의 성능을 확보한다.

#### LangChain (랭체인)
- **한글 뜻**: LLM 기반 애플리케이션을 구축하기 위한 프레임워크. 여러 AI 모델과 도구를 체인으로 연결.
- **쉬운 비유**: AI 모델들을 공장의 컨베이어 벨트(체인)에 올려놓고, 순서대로 작업을 처리하게 하는 시스템.
- **NEWKL 활용**: 모든 AI 체인을 LangChain LCEL 문법으로 구현한다. GPT-4o, Claude, Gemini 모델을 연결한다.

#### LangGraph (랭그래프)
- **한글 뜻**: LangChain 팀이 만든 AI 에이전트 워크플로우 프레임워크. 상태 그래프 기반.
- **쉬운 비유**: AI가 단순히 일직선(체인)으로 작업하는 대신, 갈림길에서 스스로 판단하고 돌아가기도 하는 지능형 내비게이션.
- **NEWKL 활용**: CREATOR 7단계의 복잡한 워크플로우를 LangGraph 상태 그래프로 구현한다. Human-in-the-Loop 포함.

#### LCP (Largest Contentful Paint)
- **한글 뜻**: 최대 콘텐츠 페인트. 페이지의 주요 콘텐츠가 화면에 표시되기까지 걸리는 시간.
- **쉬운 비유**: 식당에 들어가서 메인 요리가 나오기까지 걸리는 시간. 빠를수록 좋다.
- **NEWKL 활용**: 2.5초 이내의 LCP를 목표로 이미지 최적화, SSR, CDN을 활용한다.

#### LLM (Large Language Model)
- **한글 뜻**: 대규모 언어 모델. 방대한 텍스트 데이터를 학습하여 자연어를 이해하고 생성하는 AI 모델.
- **쉬운 비유**: 세상의 모든 책을 읽은 AI. 질문하면 학습한 지식을 바탕으로 답변을 생성한다.
- **NEWKL 활용**: GPT-4o, Claude 3.5 Sonnet, Gemini 등 LLM을 활용하여 학습 콘텐츠를 자동 생성한다.

### ㄹ (영문 R)

#### RAG (Retrieval-Augmented Generation)
- **한글 뜻**: 검색 증강 생성. 외부 지식을 검색하여 AI 모델의 답변 품질을 향상시키는 기법.
- **쉬운 비유**: 시험 볼 때 교과서를 참고하는 것. AI가 답변하기 전에 관련 자료를 찾아보고 더 정확하게 답한다.
- **NEWKL 활용**: 기업 교육 자료, 기존 학습 콘텐츠를 Vector DB에 저장하고, AI가 콘텐츠 생성 시 참조하여 정확도를 높인다.

### ㅇ (영문 U)

#### UI/UX
- **한글 뜻**: UI(사용자 인터페이스: 눈에 보이는 화면) / UX(사용자 경험: 사용 과정의 전체 느낌)
- **쉬운 비유**: UI는 식당의 인테리어와 메뉴판 디자인, UX는 주문부터 식사, 결제까지의 전체 경험.
- **NEWKL 활용**: Shadcn UI로 일관된 UI를 구성하고, FKDS 모델에 따라 학습자의 UX를 최적화한다.

### ㅇ (영문 W)

#### WebSocket (웹소켓)
- **한글 뜻**: 클라이언트와 서버 간 양방향 실시간 통신을 위한 프로토콜
- **쉬운 비유**: 전화 통화. HTTP가 편지(보내고 답장 기다리기)라면, WebSocket은 전화(양방향 실시간 대화).
- **NEWKL 활용**: 실시간 협업, 채팅, AI 콘텐츠 생성 상태 업데이트 등에 WebSocket을 사용한다.

## D. 자주 묻는 질문 (FAQ)

> 초보 개발자가 자주 겪는 문제와 해결법을 정리했습니다.

### 1. npm install 실패 시

**증상**: `npm install` 또는 `pnpm install` 실행 시 에러 발생

**해결법**:
```bash
# 1. node_modules와 lock 파일 삭제 후 재설치
rm -rf node_modules pnpm-lock.yaml
pnpm install

# 2. Node.js 버전 확인 (프로젝트 요구 버전과 일치하는지)
node -v

# 3. 캐시 정리
pnpm store prune
npm cache clean --force

# 4. 권한 문제 시 (Linux/Mac)
sudo chown -R $(whoami) ~/.npm
```

### 2. port already in use 에러

**증상**: `Error: listen EADDRINUSE: address already in use :::3000`

**해결법**:
```bash
# 해당 포트를 사용하는 프로세스 찾기
lsof -i :3000

# 프로세스 종료
kill -9 <PID>

# 또는 한 번에 처리
npx kill-port 3000

# 다른 포트로 실행
PORT=3001 pnpm dev
```

### 3. TypeScript 타입 에러

**증상**: `Type 'X' is not assignable to type 'Y'`

**해결법**:
```bash
# 1. 타입 정의 파일 업데이트
pnpm add -D @types/node @types/react

# 2. tsconfig.json의 strict 모드 확인
# "strict": true가 설정되어 있으면 타입을 정확히 지정해야 함

# 3. 타입 검사 실행
npx tsc --noEmit

# 4. 임시 해결 (권장하지 않음)
# 코드에서 // @ts-ignore 또는 as any 사용 (가능하면 올바른 타입 지정 권장)
```

### 4. Docker build 실패

**증상**: Docker 이미지 빌드 중 에러 발생

**해결법**:
```bash
# 1. Docker Desktop 실행 확인
docker info

# 2. 캐시 없이 재빌드
docker build --no-cache -t myapp .

# 3. 디스크 공간 확인 및 정리
docker system prune -a

# 4. Dockerfile 문법 확인
# COPY, RUN 등의 경로가 .dockerignore에 의해 제외되지 않았는지 확인

# 5. 멀티 스테이지 빌드 시 스테이지 이름 확인
docker build --target builder .
```

### 5. GCP 인증 오류

**증상**: `UNAUTHENTICATED` 또는 `Permission denied` 에러

**해결법**:
```bash
# 1. 로그인 상태 확인
gcloud auth list

# 2. 재로그인
gcloud auth login
gcloud auth application-default login

# 3. 프로젝트 설정 확인
gcloud config get-value project
gcloud config set project YOUR_PROJECT_ID

# 4. 서비스 계정 키 파일 설정
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service-account-key.json"

# 5. 필요한 API 활성화
gcloud services enable run.googleapis.com
```

### 6. CORS 에러

**증상**: `Access to XMLHttpRequest at '...' from origin '...' has been blocked by CORS policy`

**해결법**:
```python
# FastAPI에서 CORS 설정
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],  # 프론트엔드 주소
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```
```typescript
// NestJS에서 CORS 설정
// main.ts
app.enableCors({
  origin: 'http://localhost:3000',
  credentials: true,
});
```

**증상**: `process.env.API_URL`이 undefined로 나옴

**해결법**:

```bash
# 1. .env 파일 위치 확인 (프로젝트 루트에 있어야 함)
ls -la .env*

# .env.local
NEXT_PUBLIC_API_URL=http://localhost:8000

# 3. 서버 재시작 (환경변수 변경 후 필수)
# 개발 서버를 Ctrl+C로 종료 후 다시 실행

# 4. Docker에서 환경변수 전달
docker run -e API_URL=http://api:8000 myapp
```

### 9. DB 연결 실패

**증상**: `Connection refused` 또는 `could not connect to server`

**해결법**:
```bash
# 1. DB 서비스 실행 확인
docker compose ps  # Docker로 실행한 경우
pg_isready -h localhost -p 5432  # PostgreSQL 직접 확인

# 2. 연결 문자열 확인
```
