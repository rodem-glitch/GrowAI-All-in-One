## 9. AI 통합

### 용어 정리 (처음 보는 분을 위해)

| 용어 | 뜻 |
|------|-----|
| LLM | Large Language Model, 대규모 언어 모델 (예: GPT, Gemini, Claude) |
| 프롬프트 | AI에게 보내는 질문/지시 텍스트 |
| 토큰 | AI가 텍스트를 처리하는 최소 단위 (한글 1글자 = 약 2~3 토큰) |

| Vertex AI | Google Cloud의 AI/ML 통합 플랫폼 |
| LangChain | AI 앱 개발 프레임워크 |
| LangGraph | LangChain 기반 워크플로우 엔진 (상태 머신) |
| MCP | Model Context Protocol, AI 모델이 외부 도구를 사용하는 표준 규약 |

#### 9.1.3 Next.js에서 Gemini 사용하기

```typescript
// ============================================================
// 파일: src/lib/gemini.ts
// 목적: Gemini AI 클라이언트 설정 및 유틸리티 함수
// ============================================================

import { GoogleGenerativeAI } from "@google/generative-ai";

// Gemini 클라이언트 생성
// process.env.GEMINI_API_KEY는 .env.local 파일에서 읽어옴
const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

// 모델 선택
// - gemini-2.5-pro: 가장 높은 성능, 복잡한 추론에 적합
// - gemini-2.5-flash: 빠른 응답, 비용 절감
// - gemini-2.0-flash: 가장 빠르고 저렴
const model = genAI.getGenerativeModel({
  model: "gemini-2.5-pro",
  generationConfig: {
    temperature: 0.7,    // 0 = 정확한 답변, 1 = 창의적 답변
    topP: 0.9,           // 상위 90% 확률 토큰에서 선택
    maxOutputTokens: 8192, // 최대 출력 길이
  },
});

// ------------------------------------------------------------
// 기본 텍스트 생성 함수
// 사용 예: const answer = await generateText("한국의 수도는?");
// ------------------------------------------------------------
export async function generateText(prompt: string): Promise<string> {
  try {
    const result = await model.generateContent(prompt);
    const response = result.response;
    return response.text();
  } catch (error: unknown) {
    // 에러 발생 시 원인 파악을 위한 로그
    if (error instanceof Error) {
      console.error("Gemini API 에러:", error.message);

      // 429 에러 = 요청 한도 초과 (무료 플랜: 분당 15회)
      if (error.message.includes("429")) {
        throw new Error("API 요청 한도를 초과했습니다. 잠시 후 다시 시도하세요.");
      }
      // 403 에러 = API 키가 유효하지 않음
      if (error.message.includes("403")) {
        throw new Error("API 키가 유효하지 않습니다. 키를 다시 확인하세요.");
      }
    }
    throw error;
  }
}

// ------------------------------------------------------------
// 교안 분석 함수 (CREATOR C단계)
// 입력: 원본 교안 텍스트
// 출력: 구조화된 분석 결과 (JSON)
// ------------------------------------------------------------
export async function analyzeDocument(text: string) {
  const prompt = `당신은 교육 콘텐츠 분석 전문가입니다.
다음 교안을 분석하여 CREATOR 7단계로 구조화하세요.

[분석 기준]
- C(컨셉): 핵심 학습 목표, 대상 학습자, 선수 지식
- R(경로설계): 학습 순서, 모듈 구성, 예상 소요 시간
- E(경험설계): 상호작용 요소, 실습 활동, 참여 방법
- A(산출물생성): 필요한 콘텐츠 유형 (영상/퀴즈/문서)
- T(변화적용): 학습 후 기대 변화, 평가 기준
- O(최적운영): 운영 시 주의사항, 피드백 수집 방법
- R(성찰): 개선 포인트, 데이터 분석 항목

[교안 원문]
${text}

반드시 JSON 형식으로 응답하세요.`;

  const result = await generateText(prompt);

  // JSON 파싱 시도
  try {
    return JSON.parse(result);
  } catch {
    // JSON 파싱 실패 시 원본 텍스트 반환
    console.warn("JSON 파싱 실패, 원본 텍스트를 반환합니다.");
    return { raw: result };
  }
}

// ------------------------------------------------------------
// 스트리밍 생성 함수 (실시간으로 텍스트가 한 글자씩 나옴)
// 사용 예: 채팅 UI에서 타이핑 효과 구현
// ------------------------------------------------------------
export async function generateTextStream(
  prompt: string,
  onChunk: (chunk: string) => void // 텍스트 조각이 올 때마다 호출되는 콜백
): Promise<string> {
  const result = await model.generateContentStream(prompt);

  let fullText = "";
  for await (const chunk of result.stream) {
    const text = chunk.text();
    fullText += text;
    onChunk(text); // UI 업데이트용 콜백 호출
  }

  return fullText;
}

// ------------------------------------------------------------
// 멀티모달: 이미지 + 텍스트 동시 분석
// 사용 예: 교안에 포함된 이미지를 AI가 해석
// ------------------------------------------------------------
export async function analyzeImage(
  imageBase64: string,   // Base64로 인코딩된 이미지
  mimeType: string,      // 예: "image/png", "image/jpeg"
  question: string       // 이미지에 대한 질문
): Promise<string> {
  const result = await model.generateContent([
    question,
    {
      inlineData: {
        data: imageBase64,
        mimeType: mimeType,
      },
    },
  ]);

  return result.response.text();
}
```

```typescript
// ============================================================
// 파일: src/lib/claude.ts
// 목적: Claude AI 클라이언트 설정
// ============================================================

import Anthropic from "@anthropic-ai/sdk";

// Claude 클라이언트 생성
const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY!,
});

// ------------------------------------------------------------
// Claude로 텍스트 생성
// Claude는 특히 한국어 이해, 코드 생성, 교육 콘텐츠에 강함
// ------------------------------------------------------------
export async function generateWithClaude(
  systemPrompt: string,   // 시스템 프롬프트 (AI의 역할 설정)
  userMessage: string      // 사용자 메시지
): Promise<string> {
  const message = await anthropic.messages.create({
    model: "claude-sonnet-4-20250514",  // Claude 3.5 Sonnet (빠르고 똑똑)
    max_tokens: 4096,                       // 최대 출력 길이
    system: systemPrompt,                   // 시스템 프롬프트
    messages: [
      {
        role: "user",
        content: userMessage,
      },
    ],
  });

  // Claude 응답에서 텍스트 추출
  const textBlock = message.content.find((block) => block.type === "text");
  return textBlock ? textBlock.text : "";
}

// ------------------------------------------------------------
// FKDS 모델 기반 퀴즈 생성
// F(Feeling) → K(Knowing) → D(Doing) → S(Sharing)
// ------------------------------------------------------------
export async function generateFKDSQuiz(topic: string, level: string) {
  const systemPrompt = `당신은 FKDS 교육 모델 전문가입니다.
학습자의 단계에 맞는 퀴즈를 생성합니다.

- F(Feeling): 감정/흥미 유발 질문 (예: "~에 대해 어떻게 느끼시나요?")
- K(Knowing): 지식 확인 질문 (예: "~의 정의는 무엇인가요?")
- D(Doing): 실습/적용 질문 (예: "~를 직접 해보세요")
- S(Sharing): 공유/토론 질문 (예: "~에 대한 의견을 공유하세요")

반드시 JSON 배열로 응답하세요.`;

  const userMessage = `주제: ${topic}\n난이도: ${level}\n각 FKDS 단계별 2문제씩, 총 8문제를 생성하세요.`;

  const result = await generateWithClaude(systemPrompt, userMessage);

  try {
    return JSON.parse(result);
  } catch {
    console.warn("Claude 응답 JSON 파싱 실패");
    return { raw: result };
  }
}

// ------------------------------------------------------------
// Claude 스트리밍 (실시간 응답)
// ------------------------------------------------------------
export async function streamClaude(
  prompt: string,
  onChunk: (text: string) => void
): Promise<string> {
  let fullText = "";

  // stream() 메서드로 스트리밍 호출
  const stream = anthropic.messages.stream({
    model: "claude-sonnet-4-20250514",
    max_tokens: 4096,
    messages: [{ role: "user", content: prompt }],
  });

  // 텍스트 조각이 올 때마다 콜백 호출
  stream.on("text", (text) => {
    fullText += text;
    onChunk(text);
  });

  // 스트리밍 완료 대기
  await stream.finalMessage();
  return fullText;
}
```

```typescript
// ============================================================
// 파일: src/lib/ai-router.ts
// 목적: 작업 유형에 따라 최적의 AI 모델을 자동 선택

import { generateText as geminiGenerate } from "./gemini";

// 작업 유형에 따른 모델 자동 선택
// Gemini: 멀티모달, 긴 문서 분석, 코드 생성에 강함
// Claude: 한국어 자연어 처리, 교육 콘텐츠, 세밀한 지시 따르기에 강함
type TaskType =
  | "document_analysis"    // 문서 분석 → Gemini (긴 컨텍스트)
  | "quiz_generation"      // 퀴즈 생성 → Claude (교육 전문)
  | "content_writing"      // 콘텐츠 작성 → Claude (한국어 강점)
  | "image_analysis"       // 이미지 분석 → Gemini (멀티모달)
  | "code_generation";     // 코드 생성 → Gemini (코드 특화)

export async function aiGenerate(task: TaskType, prompt: string): Promise<string> {
  switch (task) {
    case "document_analysis":
    case "image_analysis":
    case "code_generation":
      console.log(`[AI 라우터] Gemini 선택 (작업: ${task})`);
      return geminiGenerate(prompt);

    case "quiz_generation":
    case "content_writing":
      console.log(`[AI 라우터] Claude 선택 (작업: ${task})`);
      return generateWithClaude("당신은 교육 콘텐츠 전문가입니다.", prompt);

    default:
      // 기본값: Gemini 사용
      return geminiGenerate(prompt);
  }
}
```

#### 9.3.2 영상 생성 코드

```python
# ============================================================
# 파일: app/chains/video_generator.py
# 목적: Vertex AI Veo 3.1로 AI 영상 생성
# ============================================================

from google.cloud import aiplatform
from google.protobuf import json_format
from google.protobuf.struct_pb2 import Value
import time
import json

# GCP 프로젝트 설정
PROJECT_ID = "growai-prod"           # 본인의 GCP 프로젝트 ID
LOCATION = "us-central1"            # Veo는 현재 us-central1만 지원
VEO_ENDPOINT = (
    f"projects/{PROJECT_ID}/locations/{LOCATION}"
    f"/publishers/google/models/veo-3.1-generate-001"
)


def generate_video(
    prompt: str,
    duration: int = 8,
    aspect_ratio: str = "16:9",
    output_gcs_uri: str | None = None,
) -> dict:
    """
    AI 영상 생성

    매개변수:
        prompt: 영상 설명 (한국어 가능)
                예: "밝은 교실에서 학생들이 태블릿으로 학습하는 모습"
        duration: 영상 길이 (초), 5~60초 사이
        aspect_ratio: 화면 비율 ("16:9", "9:16", "1:1")
        output_gcs_uri: 결과 저장 GCS 경로 (선택)

    반환값:
        dict: 생성된 영상 정보 (URL, 메타데이터 등)
    """
    # Vertex AI 클라이언트 초기화
    client_options = {"api_endpoint": f"{LOCATION}-aiplatform.googleapis.com"}
    client = aiplatform.gapic.PredictionServiceClient(
        client_options=client_options
    )

    # 요청 데이터 구성
    instance = json_format.ParseDict(
        {
            "prompt": prompt,
            "videoConfig": {
                "aspectRatio": aspect_ratio,
                "numberOfVideos": 1,          # 생성할 영상 수
                "durationSeconds": duration,   # 영상 길이
                "personGeneration": "dont_allow",  # 인물 생성 차단 (저작권 안전)
            },
        },
        Value(),
    )

    # API 호출 (영상 생성에는 1~5분 소요)
    print(f"[Veo] 영상 생성 시작: '{prompt[:50]}...'")
    print(f"[Veo] 길이: {duration}초, 비율: {aspect_ratio}")

    response = client.predict(
        endpoint=VEO_ENDPOINT,
        instances=[instance],
    )

    # 결과 처리
    predictions = response.predictions
    if predictions:
        result = json_format.MessageToDict(predictions[0])
        print(f"[Veo] 영상 생성 완료!")
        return result
    else:
        raise RuntimeError("영상 생성 실패: 응답에 predictions가 없습니다.")


def generate_education_video(
    topic: str,
    style: str = "친근한 설명",
    language: str = "ko",
) -> dict:
    """
    교육용 영상 자동 생성 (주제만 입력하면 프롬프트 자동 작성)

    매개변수:
        topic: 학습 주제 (예: "파이썬 반복문")
        style: 영상 스타일 (예: "친근한 설명", "공식적인 강의")
        language: 언어 코드
    """
    # 교육 영상에 최적화된 프롬프트 구성
```

### 9.4 LangGraph CREATOR 7단계 워크플로우

#### 9.4.1 LangGraph란?

```
LangGraph = LangChain + 상태 머신(State Machine)

일반 코드:  함수A() → 함수B() → 함수C()  (한 줄로 실행)
LangGraph:  노드A → 조건 분기 → 노드B or 노드C → 합류  (복잡한 흐름 가능)

장점:
- 중간에 사람이 검토/수정 가능 (Human-in-the-Loop)
- 실패 시 해당 단계만 재시작 가능
- 상태를 저장하고 나중에 이어서 실행 가능
```

#### 9.4.2 설치

```bash
# LangGraph 및 관련 패키지 설치
pip install langgraph langchain langchain-google-genai langchain-anthropic

# 또는 uv 사용 시:
uv add langgraph langchain langchain-google-genai langchain-anthropic
```

#### 9.4.3 CREATOR 7단계 구현

```python
# ============================================================
# 파일: app/chains/creator_workflow.py
# 목적: CREATOR 7단계 워크플로우를 LangGraph로 구현
#
# CREATOR 7단계:
#   C(컨셉) → R(경로설계) → E(경험설계) → A(산출물생성)
#   → T(변화적용) → O(최적운영) → R(성찰)
# ============================================================

from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain_anthropic import ChatAnthropic
from langchain_core.messages import HumanMessage, SystemMessage
from typing import TypedDict, Literal

# ============================================================
# 1단계: 상태(State) 정의
# 워크플로우가 진행되는 동안 기억해야 할 모든 정보
# ============================================================
class CreatorState(TypedDict):
    # 입력 데이터
    document: str            # 원본 교안/원고
    target_audience: str     # 대상 학습자 (예: "대학생", "직장인")
    difficulty: str          # 난이도 (예: "초급", "중급", "고급")

    # 각 단계 결과물
    concept: str             # C단계: 컨셉 분석 결과
    route: str               # R단계: 경로 설계 결과
    experience: str          # E단계: 경험 설계 결과
    artifact: str            # A단계: 산출물 생성 결과
    transformation: str      # T단계: 변화 적용 결과
    operation: str           # O단계: 최적 운영 결과
    reflection: str          # R단계: 성찰 결과

    # 메타데이터
    current_step: str        # 현재 진행 중인 단계
    status: str              # 전체 상태 ("in_progress", "completed", "failed")
    human_feedback: str      # 사람 검토 피드백 (있을 경우)
    error_message: str       # 에러 메시지 (실패 시)


# ============================================================
# 2단계: AI 모델 초기화
# ============================================================

    model="gemini-2.5-pro",
    temperature=0.3,         # 분석은 정확하게 (낮은 temperature)
)

# Claude: 콘텐츠 생성에 사용
claude = ChatAnthropic(
    model="claude-sonnet-4-20250514",
    temperature=0.7,         # 콘텐츠는 창의적으로 (높은 temperature)
)


# ============================================================
# 3단계: 각 노드(단계) 함수 정의
# ============================================================

async def step_concept(state: CreatorState) -> dict:
    """
    C단계 - 컨셉 분석
    입력 교안을 분석하여 핵심 학습 목표와 대상을 파악
    """
    print("[CREATOR] C단계 - 컨셉 분석 시작...")

    messages = [
        SystemMessage(content="""당신은 교육 콘텐츠 분석 전문가입니다.
입력된 교안을 분석하여 다음 항목을 JSON으로 반환하세요:
{
  "learning_objectives": ["학습 목표 1", "학습 목표 2"],
  "core_concepts": ["핵심 개념 1", "핵심 개념 2"],
  "prerequisites": ["선수 지식 1"],

  "target_level": "초급/중급/고급"

        HumanMessage(content=f"""[대상 학습자] {state.get('target_audience', '일반')}
[난이도] {state.get('difficulty', '중급')}

    ]

    # Gemini로 분석 (긴 문서 분석에 적합)
    response = await gemini.ainvoke(messages)
    print("[CREATOR] C단계 완료!")

    return {
        "concept": response.content,
        "current_step": "concept",
        "status": "in_progress",
    }

    """

async def human_review(state: CreatorState) -> dict:
    """
    A단계(산출물 생성) 후 사람이 검토하는 단계
    자동으로 진행하지 않고 사람의 승인을 기다림
    """
    print("[CREATOR] === 사람 검토 대기 중 ===")
    print("[CREATOR] 산출물을 검토하고 피드백을 입력하세요.")
    # 실제 구현에서는 웹 UI에서 검토 후 feedback을 전달
    return {"current_step": "human_review"}


def should_revise(state: CreatorState) -> Literal["revise", "continue"]:
    """
    사람 검토 후 수정이 필요한지 판단하는 조건 분기
    """
    feedback = state.get("human_feedback", "")
    if feedback and "수정" in feedback:
        return "revise"    # A단계로 돌아가서 재생성
    return "continue"      # 다음 단계(T)로 진행


# ============================================================
# 5단계: 워크플로우 그래프 구성
# ============================================================

def build_creator_workflow():
    """
    CREATOR 7단계 워크플로우를 LangGraph 그래프로 구성

    흐름도:
    START → C → R → E → A → (사람 검토) → T → O → R → END
                              ↑     ↓ (수정 필요 시)
                              └─────┘
    """
    # 그래프 생성
    workflow = StateGraph(CreatorState)

    # --- 노드 추가 (각 단계를 노드로 등록) ---
    workflow.add_node("concept", step_concept)           # C단계
    workflow.add_node("route", step_route)               # R단계
    workflow.add_node("experience", step_experience)     # E단계
    workflow.add_node("artifact", step_artifact)         # A단계
    workflow.add_node("human_review", human_review)      # 사람 검토
    workflow.add_node("transformation", step_transformation)  # T단계
    workflow.add_node("operation", step_operation)       # O단계
    workflow.add_node("reflection", step_reflection)     # R(성찰)단계

    # --- 엣지(연결) 추가 ---
    workflow.add_edge(START, "concept")                  # 시작 → C
    workflow.add_edge("concept", "route")                # C → R
    workflow.add_edge("route", "experience")             # R → E
    workflow.add_edge("experience", "artifact")          # E → A
    workflow.add_edge("artifact", "human_review")        # A → 사람 검토

    # 조건부 분기: 사람 검토 결과에 따라 분기
    workflow.add_conditional_edges(
        "human_review",
        should_revise,
        {
            "revise": "artifact",          # 수정 필요 → A단계로 돌아감
            "continue": "transformation",  # 승인 → T단계로 진행
        },
    )

    workflow.add_edge("transformation", "operation")     # T → O
    workflow.add_edge("operation", "reflection")         # O → R(성찰)
    workflow.add_edge("reflection", END)                 # R(성찰) → 종료

    # 체크포인트 저장소 (중간 상태 저장, 이어서 실행 가능)
    checkpointer = MemorySaver()

    # 컴파일 (실행 가능한 앱으로 변환)
    app = workflow.compile(
        checkpointer=checkpointer,
        interrupt_before=["human_review"],  # 사람 검토 전에 중단
    )

    return app


# ============================================================
# 6단계: 실행 예시
# ============================================================

async def run_creator_workflow(document: str) -> dict:
    """
    CREATOR 워크플로우 실행

    매개변수:
        document: 원본 교안 텍스트

    반환값:
        dict: 모든 단계의 결과물
    """
    app = build_creator_workflow()

    # 초기 상태 설정
    initial_state = {
        "document": document,
        "target_audience": "대학생",
        "difficulty": "중급",
        "current_step": "",
        "status": "in_progress",
    }

    # 스레드 ID로 실행 상태 관리 (여러 요청 동시 처리 가능)
    config = {"configurable": {"thread_id": "thread-001"}}

    # 워크플로우 실행
    result = await app.ainvoke(initial_state, config)

    return result


# ============================================================
# 7단계: main 함수 (직접 실행 시)
# ============================================================

if __name__ == "__main__":
    import asyncio

    sample_document = """
    제목: 파이썬 프로그래밍 기초
    1장: 변수와 자료형
    - 변수 선언 방법
    - 숫자, 문자열, 리스트
    2장: 조건문과 반복문
    - if/elif/else
    - for/while 루프
    """

    result = asyncio.run(run_creator_workflow(sample_document))
    print("\n=== CREATOR 워크플로우 완료 ===")
    print(f"상태: {result.get('status')}")
```

### 9.5 MCP (Model Context Protocol)

#### 9.5.1 MCP란?

```
MCP = AI 모델이 외부 도구를 안전하게 사용하는 표준 규약

비유:
- USB = 컴퓨터가 다양한 기기를 연결하는 표준 → MCP = AI가 다양한 도구를 연결하는 표준
- AI가 직접 DB 조회, 파일 읽기, API 호출 등을 할 수 있게 해줌

구조:
  [AI 모델] ←MCP→ [MCP 서버] ←→ [DB / 파일 / API]
```

#### 9.5.2 MCP 서버 예시

```bash
# PostgreSQL MCP 서버 설치 (AI가 DB를 직접 조회할 수 있게)
npm install @modelcontextprotocol/server-postgres

# 파일시스템 MCP 서버 설치 (AI가 파일을 읽고 쓸 수 있게)
```
