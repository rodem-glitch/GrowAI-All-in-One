## 1. Hero 섹션 영상 쇼케이스

### 개요
웹사이트 첫 화면에서 AI 영상 생성 기술력을 즉각적으로 체감시키는 풀스크린 영상 배경 구현.

### 구현 전략

#### 풀스크린 AI 생성 영상 배경
- `autoplay`, `muted`, `loop` 속성으로 끊김 없는 배경 영상 재생
- 영상 위에 반투명 오버레이 + 타이포그래피로 브랜드 메시지 전달
- 영상 교체 주기: 월 1회 (최신 AI 생성 결과물 반영)

#### AV1 코덱 + 적응형 비트레이트
```html
<video autoplay muted loop playsinline>
  <source src="/hero/showcase-4k.av1.mp4" type="video/mp4; codecs=av01.0.12M.08">
  <source src="/hero/showcase-4k.hevc.mp4" type="video/mp4; codecs=hvc1">
  <source src="/hero/showcase-1080.h264.mp4" type="video/mp4">
</video>
```
- AV1 우선 제공: 동일 품질 대비 30~50% 용량 절감
- HEVC 폴백: Safari/iOS 대응
- H.264 최종 폴백: 레거시 브라우저 호환
- DASH/HLS 적응형 스트리밍으로 네트워크 상태에 따른 품질 자동 조정

#### 모바일 최적화
- 모바일 기기 감지 시 정적 이미지(WebP/AVIF) + 재생 버튼 UI 표시
- 사용자가 명시적으로 재생 버튼을 탭해야 영상 로드 (데이터 절약)
- `prefers-reduced-motion` 미디어 쿼리 대응
- 모바일 영상: 720p 이하, 15초 이내 루프

## 2. 실시간 AI 데모

### 개요
방문자가 직접 텍스트를 입력하면 AI가 영상을 생성하는 과정을 실시간으로 체험할 수 있는 인터랙티브 데모 섹션.

### 구현 전략

#### 텍스트 입력 → AI 영상 생성 미리보기
- 프롬프트 입력창: 자연어로 원하는 영상 시나리오 기술
- 생성 과정 실시간 스트리밍: 프레임 단위 렌더링 과정 시각화
- 최종 결과물: 10~15초 분량의 미리보기 영상 제공

#### WebSocket 기반 진행률 표시
```
[연결] → [프롬프트 분석: 10%] → [장면 구성: 30%] → [프레임 생성: 50~90%] → [후처리: 95%] → [완료: 100%]
```
- 단계별 진행 상태를 시각적 프로그레스 바로 표시
- 각 단계에서 현재 처리 중인 내용 텍스트 안내
- 예상 소요 시간 표시

#### 샘플 프롬프트 (원클릭 체험)
- "교육용 3D 캐릭터가 인사하는 장면"
- "제품 언박싱 영상 (미니멀 스타일)"
- "자연 풍경 타임랩스 (해질녘 → 밤하늘)"
- "기업 소개 영상 (모던 인포그래픽)"
- 카테고리별 3~5개 샘플 프롬프트 버튼 제공

### 제한 및 안전장치
- 비회원: 1일 1회 체험 제한 (쿠키/IP 기반)
- 회원: 1일 5회 제한
- 부적절한 프롬프트 필터링 (콘텐츠 모더레이션)
- 생성 큐 관리: 동시 요청 수 제한 및 대기열 안내

## 3. 포트폴리오 갤러리

### 개요
AI가 생성한 다양한 영상 결과물을 효과적으로 전시하는 갤러리 섹션.

### 구현 전략

#### Masonry 레이아웃
- CSS Grid + JavaScript 기반 동적 Masonry 배치
- 영상 썸네일 비율 유지 (16:9, 9:16, 1:1 등 다양한 비율 혼합)
- 반응형 열 수: 데스크톱 4열 → 태블릿 2열 → 모바일 1열
- CSS `columns` 또는 `grid-template-rows: masonry` (실험적) 활용

#### Infinite Scroll + 카테고리 필터
- 카테고리 필터:
  - 산업별: 교육, 마케팅, 엔터테인먼트, 기업홍보
  - 스타일별: 실사, 3D, 2D 애니메이션, 모션 그래픽
  - 용도별: 광고, 교육 콘텐츠, 소셜 미디어, 프레젠테이션
- Intersection Observer 기반 무한 스크롤
- 페이지당 12개 영상 로드
- 스켈레톤 UI로 로딩 상태 표시

#### 영상 호버 자동 재생
- 데스크톱: 마우스 호버 시 3초 미리보기 자동 재생 (음소거)
- 호버 아웃 시 정지 및 썸네일 복귀
- 미리보기용 경량 클립: 720p, 3초, WebM 포맷
- 동시 재생 제한: 최대 1개 영상만 미리보기 활성화

#### Lightbox 모달
- 전체화면 모달에서 원본 품질 영상 재생
- 영상 정보 표시: 해상도, 생성 소요 시간, 사용된 프롬프트
- 좌우 네비게이션으로 갤러리 탐색
- 공유 버튼 (링크 복사, SNS 공유)
- 키보드 단축키: ESC(닫기), 좌우 화살표(이동), Space(재생/정지)

## 5. 인터랙티브 타임라인

### 개요
CREATOR 7단계 프로세스를 스크롤 기반 애니메이션으로 시각화하여, 각 단계에서 AI가 어떤 결과물을 생성하는지 보여주는 섹션.

### CREATOR 7단계 시각화

#### C - Concept (컨셉)
- 스크롤 트리거: 프롬프트 입력 애니메이션
- 결과물 쇼케이스: AI가 분석한 컨셉 문서, 무드보드 자동 생성

#### R - Route (경로설계)
- 스크롤 트리거: 마인드맵 노드가 펼쳐지는 애니메이션
- 결과물 쇼케이스: 학습 경로 흐름도, 커리큘럼 구조

#### E - Experience (경험설계)
- 스크롤 트리거: 스토리보드 프레임이 순차 등장
- 결과물 쇼케이스: 인터랙션 시나리오, UX 플로우

#### A - Artifact (산출물생성)
- 스크롤 트리거: 영상 프레임이 실시간 렌더링되는 효과
- 결과물 쇼케이스: AI 생성 영상 클립, 3D 에셋

#### T - Transform (변화적용)
- 스크롤 트리거: 데이터 그래프가 상승하는 애니메이션
- 결과물 쇼케이스: 학습 효과 분석 대시보드

#### O - Optimize (최적운영)
- 스크롤 트리거: 기어/톱니바퀴 회전 + 수치 최적화 애니메이션
- 결과물 쇼케이스: A/B 테스트 결과, 성능 최적화 리포트

#### R - Reflect (성찰)
- 스크롤 트리거: 순환 화살표 + 피드백 루프 애니메이션
- 결과물 쇼케이스: AI 개선 제안서, 차기 콘텐츠 추천

### 기술 구현
- GSAP ScrollTrigger 또는 Framer Motion 활용
- 각 단계 간 스무스 전환 (최소 100vh 높이)
- 진행 인디케이터: 사이드바에 현재 단계 표시
- 모바일: 세로 타임라인 + 탭 전환 방식

## 7. 기술적 구현

### 핵심 Web API 활용

#### Intersection Observer (뷰포트 기반 영상 로드)
```javascript
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const video = entry.target;
      video.src = video.dataset.src;  // lazy load
      video.play();
      observer.unobserve(video);
    }
  });
}, { threshold: 0.25 });

document.querySelectorAll('video[data-src]').forEach(v => observer.observe(v));
```
- 뷰포트 진입 시에만 영상 소스 로드 및 재생
- 초기 페이지 로드 시 네트워크 요청 최소화
- threshold 0.25: 영상의 25%가 보일 때 로드 시작

#### Media Source Extensions (MSE)
- 커스텀 비디오 플레이어 구현
- 적응형 비트레이트 스트리밍 (ABR) 제어
- 버퍼 관리: 시청 중인 세그먼트만 메모리에 유지
- DRM 연동 가능 (유료 콘텐츠 보호)

#### Picture-in-Picture (PiP) API
```javascript
videoElement.addEventListener('enterpictureinpicture', () => {
  // 미니 플레이어 활성화 시 UI 조정
});

// 스크롤 시 자동 PiP 전환
const observer = new IntersectionObserver((entries) => {
  if (!entries[0].isIntersecting && videoElement.playing) {
    videoElement.requestPictureInPicture();
  }
}, { threshold: 0 });
```
- 영상 재생 중 스크롤 다운 시 자동으로 미니 플레이어 전환
- 우측 하단 고정 위치
- 닫기/복귀 버튼 제공

### 성능 최적화 전략

| 항목 | 전략 | 목표 |
|------|------|------|
| LCP | Hero 영상 포스터 이미지 preload | < 2.5초 |
| CLS | 영상 컨테이너 aspect-ratio 고정 | < 0.1 |
| FID | 메인 스레드 블로킹 최소화 | < 100ms |
| 총 전송량 | AV1 + lazy load + 적응형 비트레이트 | 초기 < 3MB |

### CDN 및 인프라
- GCP Cloud CDN + Cloud Storage: 글로벌 엣지 캐싱
- 영상 트랜스코딩: Cloud Video Intelligence API 연동
- 멀티 포맷 자동 생성: 원본 업로드 시 AV1/HEVC/H.264 자동 변환
- 지역별 최적 엣지 서버 라우팅

## 8. 성과 목표

### 핵심 KPI

| 지표 | 목표 | 측정 방법 |
|------|------|-----------|
| 데모 전환율 | > 15% | 방문자 중 AI 데모 체험 비율 |
| 평균 체류 시간 | > 3분 | Google Analytics 세션 시간 |
| 갤러리 탐색률 | > 40% | 갤러리 섹션 도달 + 상호작용 비율 |
| CTA 클릭률 | > 8% | 상담 신청 / 무료 체험 버튼 클릭 |
| 바운스율 | < 30% | 단일 페이지 이탈 비율 |
| SEO 유입 | 월 10,000+ | 자연 검색 유입 수 |

### 전환 퍼널
```
방문 (100%)
  → Hero 영상 시청 완료 (70%)
    → 실시간 데모 체험 (15%+)
      → 갤러리 탐색 (40%)
        → CTA 클릭 (8%+)
          → 회원가입/상담 신청 (3%+)
```

### A/B 테스트 계획
- Hero 영상 vs 정적 이미지: 체류 시간 비교
- 데모 섹션 위치: Above the fold vs Below the fold
- CTA 문구: "무료 체험 시작" vs "AI 영상 만들어보기"
- 갤러리 레이아웃: Masonry vs Grid vs 캐러셀

### 반복 개선 사이클
1. 주간 데이터 리뷰: 히트맵, 스크롤 깊이, 클릭 패턴 분석
2. 월간 A/B 테스트: 1~2개 실험 진행
3. 분기별 대규모 업데이트: Hero 영상 교체, 신규 포트폴리오 추가
4. CREATOR R(성찰) 단계 적용: AI 기반 사용자 행동 분석 및 자동 최적화 제안
