## 1. 현재 상태 분석

### 사용 폰트

| 폰트 | 용도 | 로딩 방식 | 비고 |
|------|------|----------|------|
| Pretendard | 한글 본문/UI | Google Fonts CDN | 외부 의존 |
| Inter | 영문 본문/UI | Google Fonts CDN | 외부 의존 |

### 현재 문제점

- **외부 CDN 의존**: Google Fonts에서 로딩하여 DNS 조회 + 연결 수립에 추가 시간 소요
- **과다한 파일 수**: Weight별 개별 파일 로딩 (Regular, Medium, SemiBold, Bold 등 6개+)
- **전체 글리프 포함**: 한글 11,172자 전체를 포함하여 불필요한 용량 발생
- **FOIT (Flash of Invisible Text)**: 폰트 로딩 전 텍스트가 보이지 않는 현상 발생
- **CLS (Cumulative Layout Shift)**: 폰트 교체 시 레이아웃 밀림 현상

### 현재 로딩 용량 (추정)

```
Pretendard Regular     ~350KB (OTF)
Pretendard Medium      ~360KB
Pretendard SemiBold    ~355KB
Pretendard Bold        ~365KB
Inter (4 weights)      ~400KB
────────────────────────────────
합계                   ~1,830KB
```

## 2. 최적화 전략

### 2.1 Self-hosting (외부 의존성 제거)

Google Fonts CDN 대신 자체 서버에서 폰트를 제공한다.

**장점:**
- DNS 조회/연결 수립 시간 제거 (약 100-300ms 단축)
- 타사 서비스 장애에 영향받지 않음
- Cache-Control 헤더를 직접 제어 가능
- GDPR 등 개인정보 이슈 해소 (Google에 사용자 IP 전송 방지)

**구현:**

```
public/
  fonts/
    pretendard/
      PretendardVariable.subset.woff2
    inter/
      InterVariable.subset.woff2
```

```css
/* 외부 CDN 제거 - 기존 */
/* @import url('https://fonts.googleapis.com/css2?family=Pretendard...'); */

/* Self-hosting 방식 */
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/PretendardVariable.subset.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
}
```

### 2.2 서브셋 (Subset) 적용

한글 전체 11,172자가 아닌, 실사용 빈도 높은 글자만 포함한다.

| 범위 | 글자 수 | 설명 |
|------|---------|------|
| KS X 1001 완성형 | 2,350자 | 한글 상용 한자/한글 |
| Basic Latin | 95자 | 영문 + 숫자 + 기호 |
| Latin Extended | ~200자 | 유럽 문자 (필요 시) |
| 기호/특수문자 | ~50자 | 화살표, 불릿 등 UI용 |

**서브셋 생성 도구:**

```bash
# pyftsubset (fonttools) 사용
pip install fonttools brotli

pyftsubset PretendardVariable.ttf \
  --output-file=PretendardVariable.subset.woff2 \
  --flavor=woff2 \
  --layout-features='*' \
  --unicodes="U+0020-007E,U+AC00-D7A3" \
  --unicodes+="U+3000-303F,U+3130-318F" \
  --unicodes+="U+2000-206F,U+2190-21FF"
```

### 2.3 WOFF2 포맷 통일

| 포맷 | 압축률 | 브라우저 지원 |
|------|--------|-------------|
| TTF/OTF | 기준 | 모든 브라우저 |
| WOFF | 40% 감소 | IE9+ |
| **WOFF2** | **50-60% 감소** | **모든 최신 브라우저** |

WOFF2는 Brotli 압축을 사용하여 TTF 대비 50-60% 용량을 절감한다. 2024년 기준 글로벌 브라우저 지원율 97% 이상이므로 WOFF2 단독 사용이 가능하다.

### 2.4 font-display: swap

```css
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/PretendardVariable.subset.woff2') format('woff2');
  font-display: swap; /* FOUT 허용, FOIT 방지 */
}
```

| 전략 | 동작 | 사용 케이스 |
|------|------|-----------|
| `auto` | 브라우저 기본값 (보통 block) | 사용하지 않음 |
| `block` | 3초간 텍스트 숨김 (FOIT) | 아이콘 폰트 |
| **`swap`** | **즉시 fallback 표시 후 교체** | **본문/UI 텍스트** |
| `fallback` | 100ms block + 3초 swap | 짧은 텍스트 |
| `optional` | 100ms block, 이후 교체 안 함 | 덜 중요한 폰트 |

본문/UI 텍스트에는 `swap`을 사용하여 사용자가 콘텐츠를 즉시 읽을 수 있게 한다.

### 2.5 Preload 적용

가장 먼저 필요한 폰트 파일을 `<link rel="preload">`로 브라우저에 미리 알린다.

```html
<head>
  <!-- 폰트 파일 preload (Critical 폰트만) -->
  <link
    rel="preload"
    href="/fonts/pretendard/PretendardVariable.subset.woff2"
    as="font"
    type="font/woff2"
    crossorigin="anonymous"
  />
  <link
    rel="preload"
    href="/fonts/inter/InterVariable.subset.woff2"
    as="font"
    type="font/woff2"
    crossorigin="anonymous"
  />
</head>
```

**주의사항:**
- `crossorigin="anonymous"` 필수 (폰트는 CORS 요청)
- preload 대상은 2-3개 이내로 제한 (과다 시 역효과)
- Self-hosting 폰트에만 적용 (CDN 폰트는 DNS prefetch 사용)

## 3. Variable Font 전환

### 기존 방식 vs Variable Font

```
[기존: Static Fonts]
PretendardThin.woff2        ~45KB
PretendardLight.woff2       ~48KB
PretendardRegular.woff2     ~50KB
PretendardMedium.woff2      ~52KB
PretendardSemiBold.woff2    ~53KB
PretendardBold.woff2        ~55KB
────────────────────────────────
합계 6파일               ~303KB (서브셋 후)

[Variable Font]
PretendardVariable.woff2    ~150KB (서브셋 후)
────────────────────────────────
합계 1파일               ~150KB
```

### 적용 방법

```css
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/PretendardVariable.subset.woff2') format('woff2');
  font-weight: 100 900;       /* 전체 weight 범위 */
  font-style: normal;
  font-display: swap;
}

/* 기존: 정해진 weight만 사용 */
.text-regular { font-weight: 400; }
.text-bold    { font-weight: 700; }

/* Variable Font: 자유로운 weight 지정 가능 */
.text-custom  { font-weight: 450; }
.text-heading { font-weight: 650; }
```

### Inter Variable Font

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter/InterVariable.subset.woff2') format('woff2');
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}
```

Inter Variable은 optical size 축도 지원하므로, 제목과 본문에서 자동으로 글리프 형태가 최적화된다.

```css
.heading {
  font-family: 'Inter';
  font-variation-settings: 'opsz' 32; /* 큰 텍스트에 최적화 */
}
```

## 4. size-adjust로 CLS 방지

폰트 로딩 전 fallback 폰트와 커스텀 폰트 사이의 크기 차이로 인해 레이아웃이 밀리는 현상(CLS)을 방지한다.

### Fallback 폰트 메트릭 맞춤

```css
/* Pretendard 대체용 fallback (시스템 폰트 기반) */
@font-face {
  font-family: 'Pretendard Fallback';
  src: local('Apple SD Gothic Neo'), local('Malgun Gothic');
  size-adjust: 99.5%;           /* 글자 크기 보정 */
  ascent-override: 105%;        /* 상단 메트릭 보정 */
  descent-override: 22%;        /* 하단 메트릭 보정 */
  line-gap-override: 0%;        /* 줄 간격 보정 */
}

/* Inter 대체용 fallback */
@font-face {
  font-family: 'Inter Fallback';
  src: local('Arial'), local('Helvetica');
  size-adjust: 107%;
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}

/* 폰트 스택 적용 */
body {
  font-family: 'Pretendard', 'Pretendard Fallback', 'Apple SD Gothic Neo',
               'Malgun Gothic', sans-serif;
}

.en-text {
  font-family: 'Inter', 'Inter Fallback', 'Arial', 'Helvetica', sans-serif;
}
```

### Next.js에서의 자동 처리

Next.js의 `next/font`를 사용하면 size-adjust가 자동으로 계산된다.

```tsx
// app/layout.tsx
import localFont from 'next/font/local';

const pretendard = localFont({
  src: '../public/fonts/pretendard/PretendardVariable.subset.woff2',
  display: 'swap',
  variable: '--font-pretendard',
  adjustFontFallback: 'Arial', // 자동 메트릭 보정
});

const inter = localFont({
  src: '../public/fonts/inter/InterVariable.subset.woff2',
  display: 'swap',
  variable: '--font-inter',
  adjustFontFallback: 'Arial',
});

export default function RootLayout({ children }) {
  return (
    <html className={`${pretendard.variable} ${inter.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

```css
/* Tailwind CSS 설정 */
/* tailwind.config.ts */
fontFamily: {
  sans: ['var(--font-pretendard)', 'var(--font-inter)', 'sans-serif'],
}
```

## 5. 한글 폰트 분할 로딩 (Unicode Range)

### 원리

한글 2,350자를 한 번에 로딩하지 않고, `unicode-range`로 분할하여 해당 글자가 페이지에 있을 때만 로딩한다.

### 분할 전략

Google Fonts의 한글 폰트 분할 방식을 참고하여 약 10-15개 청크로 나눈다.

```css
/* 청크 1: 가-깋 (기본 자음 ㄱ 시작) */
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/slice-1.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
  unicode-range: U+AC00-AD1F;
}

/* 청크 2: 까-낗 */
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/slice-2.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
  unicode-range: U+AD20-B23F;
}

/* 청크 3: 나-댛 */
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/slice-3.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
  unicode-range: U+B240-B75F;
}

/* ... 중략 ... */

/* 청크 N: Latin + 기호 */
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/pretendard/slice-latin.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
  unicode-range: U+0020-007E, U+2000-206F;
}
```

### 분할 자동화 스크립트

```python
# scripts/split_font.py
import subprocess

# 한글 유니코드 범위를 N등분
HANGUL_START = 0xAC00
HANGUL_END = 0xD7A3
CHUNK_SIZE = 500  # 글자 수 기준

chunks = []
start = HANGUL_START
while start <= HANGUL_END:
    end = min(start + CHUNK_SIZE - 1, HANGUL_END)
    chunks.append((start, end))
    start = end + 1

for i, (s, e) in enumerate(chunks):
    output = f"slice-{i+1}.woff2"
    unicode_range = f"U+{s:04X}-{e:04X}"
    cmd = [
        "pyftsubset", "PretendardVariable.ttf",
        f"--output-file={output}",
        "--flavor=woff2",
        "--layout-features=*",
        f"--unicodes={unicode_range}"
    ]
    subprocess.run(cmd, check=True)
    print(f"생성: {output} ({unicode_range})")
```

### 분할 로딩의 효과

```
전체 로딩 방식:
  초기 요청 1회 → 150KB 전체 다운로드

분할 로딩 방식:
  "안녕하세요" 표시 시 → slice-1.woff2 (~15KB)만 로딩
  스크롤 후 추가 글자 → 필요한 slice만 추가 로딩
  ────────────────────────────────
  일반적인 페이지: 30-50KB만 로딩 (전체의 20-33%)
```

## 6. 성과 목표

### 핵심 지표

| 지표 | 현재 (추정) | 목표 | 비고 |
|------|-----------|------|------|
| 폰트 총 로딩 용량 | ~1,830KB | **< 150KB** | 92% 절감 |
| 초기 로딩 폰트 | ~1,830KB | **< 50KB** | unicode-range 분할 |
| CLS (폰트 기인) | 0.05+ | **0** | size-adjust 적용 |
| 폰트 로딩 시간 | ~800ms | **< 200ms** | preload + self-host |
| 외부 요청 수 | 4-6건 | **0건** | self-hosting |
| HTTP 요청 수 (폰트) | 8-12건 | **2-4건** | Variable Font + 분할 |

### 최적화 적용 단계별 효과

```
단계 1: WOFF2 변환
  1,830KB → ~900KB (50% 감소)

단계 2: Variable Font 전환
  ~900KB → ~400KB (55% 감소)

단계 3: 서브셋 적용 (2,350자)
  ~400KB → ~150KB (62% 감소)

단계 4: Self-hosting + Preload
  로딩 시간 300ms+ 단축

단계 5: unicode-range 분할
  초기 로딩 150KB → ~50KB (67% 감소)

단계 6: size-adjust 적용
  CLS 0.05+ → 0
```
