## 1. 접근성 (WCAG 2.1 AA 준수)

### 1.1 키보드 네비게이션

모든 인터랙티브 요소는 키보드만으로 접근 및 조작 가능해야 한다.

| 요구사항 | 구현 방법 |
|----------|-----------|
| 탭 순서 보장 | `tabindex` 논리적 순서, 자연스러운 DOM 순서 우선 |
| 커스텀 컴포넌트 | `<button>`, `<a>` 등 네이티브 요소 활용, 불가시 `role` + `tabindex="0"` |
| 모달/드롭다운 | 포커스 트랩(focus trap) 적용, `Escape`키 닫기 |
| 스킵 네비게이션 | 페이지 상단 "본문 바로가기" 링크 |

```tsx
// 스킵 네비게이션 예시
<a
  href="#main-content"
  className="sr-only focus:not-sr-only focus:absolute focus:top-4 focus:left-4
             focus:z-50 focus:bg-white focus:px-4 focus:py-2 focus:rounded"
>
  본문 바로가기
</a>
```

### 1.2 스크린 리더 지원

```tsx
// 아이콘 버튼 — 시각적 텍스트 없음
<button aria-label="동영상 재생">
  <PlayIcon aria-hidden="true" />
</button>

// 폼 필드 설명
<input
  id="email"
  aria-describedby="email-help"
  aria-invalid={!!errors.email}
  aria-errormessage="email-error"
/>
<p id="email-help">업무용 이메일을 입력하세요</p>
{errors.email && <p id="email-error" role="alert">{errors.email}</p>}

// 동적 콘텐츠 알림
<div aria-live="polite" aria-atomic="true">
  {statusMessage}
</div>

// 랜드마크 역할
<nav role="navigation" aria-label="메인 메뉴">...</nav>
<main role="main" id="main-content">...</main>
<aside role="complementary" aria-label="사이드바">...</aside>
```

### 1.3 색상 대비

| 기준 | 최소 비율 | 적용 대상 |
|------|-----------|-----------|
| 일반 텍스트 | 4.5:1 | 본문, 레이블, 캡션 |
| 큰 텍스트 (18px+/14px bold+) | 3:1 | 제목, 버튼 텍스트 |
| UI 컴포넌트 | 3:1 | 아이콘, 입력 테두리, 포커스 링 |

```css

  --color-text-secondary: #4a4a6a;   /* 배경 #ffffff 대비 7.8:1 */
  --color-text-muted: #6b6b8a;       /* 배경 #ffffff 대비 4.6:1 */
  --color-brand-primary: #2563eb;    /* 배경 #ffffff 대비 4.6:1 */

}
```

### 1.4 포커스 표시

```css
/* focus-visible: 마우스 클릭 시 표시 안 함, 키보드 사용 시에만 표시 */
*:focus-visible {
  outline: 2px solid var(--color-brand-primary);
  outline-offset: 2px;
  border-radius: 2px;
}

/* 포커스 링이 잘려나가지 않도록 */
*:focus-visible {
  box-shadow: 0 0 0 2px var(--color-brand-primary);
}

/* 다크모드 대응 */
@media (prefers-color-scheme: dark) {
  *:focus-visible {
    outline-color: #93c5fd;
    box-shadow: 0 0 0 2px #93c5fd;
  }
}
```

### 1.5 모션 감소

```css
/* 시스템 설정 존중 */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

```tsx
// React 훅으로 모션 감소 감지
function usePrefersReducedMotion(): boolean {
  const [prefersReduced, setPrefersReduced] = useState(false);

  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    setPrefersReduced(mq.matches);
    const handler = (e: MediaQueryListEvent) => setPrefersReduced(e.matches);
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, []);

  return prefersReduced;
}

// 사용 예시
function HeroAnimation() {
  const reduceMotion = usePrefersReducedMotion();

  return reduceMotion
    ? <StaticHeroImage />
    : <AnimatedHeroVideo autoPlay muted />;
}
```

## 2. 다국어 확장 로드맵

### 2.1 단계별 언어 확장

| 단계 | 언어 | 코드 | 방향 | 목표 시점 |
|------|------|------|------|-----------|
| **Phase 1** (현재) | 한국어, 영어 | `ko`, `en` | LTR | 운영 중 |
| **Phase 2** | 일본어, 중국어(간체) | `ja`, `zh-CN` | LTR | Q3 2026 |
| **Phase 3** | 스페인어, 프랑스어, 독일어, 포르투갈어 | `es`, `fr`, `de`, `pt` | LTR | Q1 2027 |
| **Phase 4** | 아랍어, 태국어, 베트남어 | `ar`, `th`, `vi` | RTL/LTR | Q3 2027 |

### 2.2 언어별 고려사항

| 언어 | 특이사항 |
|------|----------|
| `ja` | 경어체 처리, 가나/한자 혼용, 세로쓰기 불필요 |
| `zh-CN` | 간체/번체 구분, 중국 내 CDN(Alibaba Cloud) 고려 |
| `ar` | RTL 레이아웃, 아랍 숫자/서양 숫자 혼용 |
| `th` | 줄바꿈 규칙(단어 구분 없음), Intl.Segmenter 활용 |
| `vi` | 성조 기호 포함 유니코드 정규화 |

## 3. i18n 아키텍처 개선

### 3.1 현재 구조 (자체 구현)

```
현재: LanguageContext + 정적 객체
├── src/i18n/ko.ts    (전체 번역을 한 파일에)
├── src/i18n/en.ts    (전체 번역을 한 파일에)
└── LanguageContext   (단순 상태 관리)
```

**문제점:**
- 모든 언어 데이터가 초기 번들에 포함
- 네임스페이스 분리 불가 — 페이지별 부분 로딩 불가능
- 복수형, 문맥, 보간 등 고급 기능 부재
- 언어 추가 시 확장성 한계

### 3.2 개선 구조 (i18next + react-i18next)


### 3.3 i18next 설정

```typescript
// src/i18n/config.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import HttpBackend from 'i18next-http-backend';
import LanguageDetector from 'i18next-browser-languagedetector';

const SUPPORTED_LANGUAGES = ['ko', 'en', 'ja', 'zh-CN', 'es', 'fr', 'de', 'pt', 'ar', 'th', 'vi'] as const;
type SupportedLanguage = typeof SUPPORTED_LANGUAGES[number];

i18n
  .use(HttpBackend)
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    fallbackLng: 'ko',
    supportedLngs: SUPPORTED_LANGUAGES,

    // 네임스페이스 설정
    ns: ['common', 'landing', 'lms', 'dashboard'],
    defaultNS: 'common',

    // 동적 로딩 — 현재 언어만 번들에 포함
    backend: {
      loadPath: '/locales/{{lng}}/{{ns}}.json',
    },

    // 언어 감지 우선순위
    detection: {
      order: ['querystring', 'cookie', 'localStorage', 'navigator'],
      caches: ['cookie', 'localStorage'],
    },

    interpolation: {
      escapeValue: false, // React가 XSS 방어 처리
    },

    react: {
      useSuspense: true,
    },
  });

export default i18n;
export { SUPPORTED_LANGUAGES };
export type { SupportedLanguage };
```

## 4. RTL (Right-to-Left) 지원

### 4.1 HTML 방향 동적 전환

```tsx
// src/app/layout.tsx
import { getDirection } from '@/i18n/utils';

export default function RootLayout({ params }: { params: { lng: string } }) {
  const dir = getDirection(params.lng); // 'ar' -> 'rtl', 나머지 -> 'ltr'

  return (
    <html lang={params.lng} dir={dir}>
      <body className={dir === 'rtl' ? 'font-arabic' : 'font-default'}>
        {children}
      </body>
    </html>
  );
}

// src/i18n/utils.ts
const RTL_LANGUAGES = ['ar', 'he', 'fa', 'ur'] as const;

export function getDirection(locale: string): 'ltr' | 'rtl' {
  return RTL_LANGUAGES.some(lang => locale.startsWith(lang)) ? 'rtl' : 'ltr';
}
```

### 4.2 Tailwind CSS RTL 변형

```javascript
// tailwind.config.ts
module.exports = {
  plugins: [
    require('tailwindcss-rtl'), // RTL 유틸리티 플러그인
  ],
};
```

```tsx
// RTL 대응 레이아웃
<div className="flex flex-row">
  {/* 논리적 속성 사용: margin-left -> margin-inline-start */}
  <nav className="ms-4">   {/* LTR: ml-4, RTL: mr-4 */}
    <ChevronIcon className="rtl:rotate-180" />  {/* RTL에서 아이콘 미러링 */}
  </nav>
  <main className="me-auto"> {/* LTR: mr-auto, RTL: ml-auto */}
    <p className="text-start">  {/* LTR: text-left, RTL: text-right */}
      {content}
    </p>
  </main>
</div>
```

### 4.3 레이아웃 미러링 체크리스트

| 항목 | LTR | RTL | CSS 속성 |
|------|-----|-----|----------|
| 텍스트 정렬 | left | right | `text-align: start` |
| 여백 방향 | margin-left | margin-right | `margin-inline-start` |
| 패딩 방향 | padding-right | padding-left | `padding-inline-end` |
| 아이콘 방향 | 원본 | 수평 반전 | `transform: scaleX(-1)` |
| 진행 바 | 좌→우 | 우→좌 | `direction: inherit` |
| 슬라이더 | 좌→우 | 우→좌 | 네이티브 지원 |

## 5. 날짜 / 숫자 / 통화 포맷

### 5.1 날짜 포맷

```typescript
// src/lib/format.ts

export function formatDate(date: Date, locale: string): string {
  return new Intl.DateTimeFormat(locale, {
    year: 'numeric',
    month: 'long',
    day: 'numeric',
  }).format(date);
}

// 결과 예시
// ko: "2026년 4월 10일"
// en: "April 10, 2026"
// ja: "2026年4月10日"
// ar: "١٠ أبريل ٢٠٢٦"

export function formatRelativeTime(date: Date, locale: string): string {
  const rtf = new Intl.RelativeTimeFormat(locale, { numeric: 'auto' });
  const diffDays = Math.round((date.getTime() - Date.now()) / 86400000);

  if (Math.abs(diffDays) < 1) return rtf.format(0, 'day');       // "오늘"
  if (Math.abs(diffDays) < 7) return rtf.format(diffDays, 'day'); // "3일 전"
  if (Math.abs(diffDays) < 30) return rtf.format(Math.round(diffDays / 7), 'week');
  return rtf.format(Math.round(diffDays / 30), 'month');
}
```

### 5.3 통화 포맷

```typescript
export function formatCurrency(
  amount: number,
  locale: string,
  currency?: string,
): string {
  // 지역별 기본 통화
  const defaultCurrencies: Record<string, string> = {
    ko: 'KRW',
    en: 'USD',
    ja: 'JPY',
    'zh-CN': 'CNY',
    es: 'EUR',
    fr: 'EUR',
    de: 'EUR',
    pt: 'BRL',
    ar: 'SAR',
    th: 'THB',
    vi: 'VND',
  };

  return new Intl.NumberFormat(locale, {
    style: 'currency',
    currency: currency ?? defaultCurrencies[locale] ?? 'USD',
  }).format(amount);
}

// 결과 예시
// ko: "₩49,000"
// en: "$49.00"
// ja: "¥4,900"
// de: "49,00 €"
// ar: "٤٩٫٠٠ ر.س."
```

## 6. 성과 목표 및 측정

### 6.1 핵심 지표

| 지표 | 현재 | 목표 | 측정 도구 |
|------|------|------|-----------|
| Lighthouse Accessibility 점수 | 미측정 | **100** | Lighthouse CI |
| WCAG 2.1 AA 위반 사항 | 미점검 | **0건** | axe-core |
| 지원 언어 수 | 2개 (ko, en) | **8개** 이상 | - |
| 번역 커버리지 | 100% (2개 언어) | 95% 이상 (전 언어) | i18next 리포트 |
| 번역 키 누락 경고 | 없음 | CI에서 자동 감지 | i18next-parser |
| RTL 레이아웃 깨짐 | 미지원 | **0건** | 시각적 회귀 테스트 |

### 6.2 자동화 파이프라인

```yaml
# .github/workflows/a11y-i18n-check.yml
name: Accessibility & i18n Check

on: [pull_request]

jobs:
  accessibility:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install & Build
        run: pnpm install && pnpm build
      - name: Lighthouse CI
        uses: treosh/lighthouse-ci-action@v11
        with:
          configPath: .lighthouserc.json
          uploadArtifacts: true
      - name: axe-core 접근성 검사
        run: pnpm exec playwright test --grep @a11y

  i18n:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: 번역 키 누락 검사
        run: npx i18next-parser --fail-on-warnings
      - name: 번역 파일 유효성 검증
        run: |
          node scripts/validate-translations.js
```

### 6.3 테스트 전략

```typescript
// e2e/accessibility.spec.ts
import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

test.describe('접근성 검사', () => {
  const pages = ['/', '/features', '/pricing', '/login', '/dashboard'];

  for (const path of pages) {
    test(`${path} 페이지 WCAG 2.1 AA 준수`, async ({ page }) => {
      await page.goto(path);
      const results = await new AxeBuilder({ page })
        .withTags(['wcag2a', 'wcag2aa', 'wcag21aa'])
        .analyze();

      expect(results.violations).toEqual([]);
    });
  }

  test('키보드 네비게이션 전체 순회', async ({ page }) => {
    await page.goto('/');
    // 첫 번째 Tab -> 스킵 네비게이션 링크
    await page.keyboard.press('Tab');
    const skipLink = page.locator('a[href="#main-content"]');
    await expect(skipLink).toBeFocused();
  });
});

// e2e/i18n.spec.ts
test.describe('다국어 전환', () => {
  const languages = ['ko', 'en', 'ja'];

  for (const lng of languages) {
    test(`${lng} 언어 전환 및 콘텐츠 표시`, async ({ page }) => {
      await page.goto(`/?lng=${lng}`);
      const html = page.locator('html');
      await expect(html).toHaveAttribute('lang', lng);
      // 번역 키가 그대로 노출되지 않는지 확인
      const body = await page.textContent('body');
      expect(body).not.toMatch(/\{\{.*\}\}/);
      expect(body).not.toMatch(/^[a-z]+\.[a-z]+\.[a-z]+$/m);
    });
  }
});
```
