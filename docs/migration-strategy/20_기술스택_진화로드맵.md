# NEWKL AI Video 플랫폼 기술 스택 진화 로드맵

> "NEWKL의 웹사이트는 AI 영상 생성 기술력의 첫 번째 증거이다."

---

## 1. 현재 기술 스택 (AS-IS)

| 레이어 | 기술 | 버전 |
|--------|------|------|
| 프레임워크 | Vite + React (CSR SPA) | 6.2 + 19 |
| 스타일 | Tailwind CSS | 4.1 |
| 라우팅 | React Router | 7.14 |
| 상태관리 | Context API + React Query | 5.97 |
| 빌드 | Vite Rollup | 6.2 |
| 배포 | Docker + Nginx + Cloud Run | - |
| 모니터링 | 없음 | - |
| SEO | CSR (검색엔진 불가) | - |

### 현재 스택의 한계

- **CSR 전용**: 모든 렌더링이 클라이언트에서 발생하여 초기 로딩 속도 저하
- **SEO 불가**: 검색엔진 크롤러가 콘텐츠를 인덱싱할 수 없음
- **번들 비대**: ~300KB JS 번들로 인해 모바일 환경에서 성능 저하
- **모니터링 부재**: 장애 감지 및 성능 추적 불가
- **글로벌 대응 미흡**: 단일 리전 배포로 해외 사용자 경험 저하

## 2. 목표 기술 스택 (TO-BE)

| 레이어 | 기술 | 전환 이유 |
|--------|------|-----------|
| 프레임워크 | Astro + React Islands | 0KB JS 정적 페이지 + 부분 하이드레이션 |
| 스타일 | Tailwind CSS + Design Tokens | W3C 표준 디자인 토큰 체계 |
| 라우팅 | Astro File Router | 정적 라우팅 최적화 |
| 상태관리 | Zustand + React Query | 경량 클라이언트 상태 + 서버 상태 분리 |
| 빌드 | Astro Build (Vite 기반) | 정적 + 하이브리드 렌더링 지원 |
| 배포 | Edge (Cloudflare) + Cloud Run | 글로벌 50ms TTFB 달성 |
| 모니터링 | Sentry + Grafana + Web Vitals | 풀스택 옵저버빌리티 확보 |
| SEO | SSG/SSR + 구조화된 데이터 | 검색 결과 1페이지 노출 |

### 목표 스택의 핵심 이점

- **Islands Architecture**: 인터랙티브가 필요한 컴포넌트만 하이드레이션하여 JS 전송량 최소화
- **하이브리드 렌더링**: 정적 페이지(SSG)와 동적 페이지(SSR)를 페이지 단위로 선택 가능
- **엣지 배포**: Cloudflare 글로벌 네트워크를 통한 초저지연 응답
- **풀스택 모니터링**: 에러 추적, 성능 메트릭, 사용자 경험 지표 통합 관리

## 5. 전환 아키텍처 다이어그램

```
[AS-IS]                              [TO-BE]
                                    
Vite + React (CSR)                  Astro + React Islands
    │                                   │
    ▼                                   ▼
┌──────────────┐                 ┌──────────────────┐
│  Single SPA  │                 │  정적 페이지 (SSG) │ ← 0KB JS
│  ~300KB JS   │       →         │  + React Islands  │ ← 부분 하이드레이션
│  CSR Only    │                 │  + SSR (동적)      │ ← SEO 완전 대응
└──────┬───────┘                 └────────┬─────────┘
       │                                  │
       ▼                                  ▼
┌──────────────┐                 ┌──────────────────┐
│  Cloud Run   │                 │  Cloudflare Edge  │ ← 글로벌 엣지
│  단일 리전    │       →         │  + Cloud Run API  │ ← 50ms TTFB
│  ~500ms TTFB │                 │  + Sentry/Grafana │ ← 옵저버빌리티
└──────────────┘                 └──────────────────┘
```
