## 1. 현재 상태 분석

### 1.1 기술 기반

| 항목 | 현재 상태 | 비고 |
|------|-----------|------|
| CSS 프레임워크 | Tailwind CSS 4 유틸리티 | JIT 컴파일 기반 |
| 컴포넌트 | 자체 구현 (Button, Badge, Avatar 등) | 재사용성 제한적 |

### 1.2 현재 과제

- 컴포넌트 일관성 부족: 서비스별로 동일 역할의 컴포넌트가 다르게 구현됨

- 문서화 미비: 신규 개발자 온보딩 시 컴포넌트 파악에 시간 소요
- 서비스 확장 시 테마 관리 어려움: 브랜드 컬러 확장이 제한적

### 2.2 Design Token: W3C 표준 전환

**현재 (Tailwind CSS 변수)**
```css
:root {
  --color-primary: #6366f1;
  --color-secondary: #8b5cf6;
}
```

**목표 (W3C Design Token Format)**
```json
{
  "color": {
    "primary": {
      "$value": "#6366f1",
      "$type": "color",
      "$description": "주요 브랜드 컬러"
    },
    "secondary": {
      "$value": "#8b5cf6",
      "$type": "color",
      "$description": "보조 브랜드 컬러"
    }
  },
  "spacing": {
    "xs": { "$value": "4px", "$type": "dimension" },
    "sm": { "$value": "8px", "$type": "dimension" },
    "md": { "$value": "16px", "$type": "dimension" },
    "lg": { "$value": "24px", "$type": "dimension" },
    "xl": { "$value": "32px", "$type": "dimension" }
  }
}
```

**토큰 계층 구조**

```
Global Tokens (원시값)
  └── Alias Tokens (의미 부여)
       └── Component Tokens (컴포넌트 전용)
```

| 계층 | 예시 | 설명 |
|------|------|------|
| Global | `color.indigo.500 = #6366f1` | 원시 색상값 |
| Alias | `color.brand.primary = {color.indigo.500}` | 의미 기반 참조 |
| Component | `button.background.default = {color.brand.primary}` | 컴포넌트 전용 |

**변환 파이프라인**

```
Figma Variables
    ↓ (Token Studio 추출)
W3C Design Token JSON
    ↓ (Style Dictionary 변환)
├── CSS Variables
├── Tailwind Config
├── TypeScript Constants
└── iOS / Android Tokens
```

### 4.3 다크모드: System Preference 자동 감지

**구현 전략**

```
테마 우선순위:
1. 사용자 수동 설정 (localStorage)
2. 시스템 환경설정 (prefers-color-scheme)
3. 기본값 (light)
```

**CSS 구현**

```css
/* 라이트 모드 (기본) */
:root {
  --color-bg: #ffffff;
  --color-text: #1a1a2e;
  --color-surface: #f8f9fa;
}

/* 다크 모드 */
[data-theme="dark"] {
  --color-bg: #0f0f23;
  --color-text: #e2e8f0;
  --color-surface: #1a1a2e;
}

/* 시스템 자동 감지 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --color-bg: #0f0f23;
    --color-text: #e2e8f0;
    --color-surface: #1a1a2e;
  }
}
```

**React 훅 구현**

```typescript
function useTheme() {
  const [theme, setTheme] = useState<'light' | 'dark' | 'system'>('system');

  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
    const handleChange = () => {
      if (theme === 'system') {
        document.documentElement.dataset.theme =
          mediaQuery.matches ? 'dark' : 'light';
      }
    };
    mediaQuery.addEventListener('change', handleChange);
    return () => mediaQuery.removeEventListener('change', handleChange);
  }, [theme]);

  return { theme, setTheme };
}
```

## 5. 애니메이션 시스템

### 5.1 Transition Tokens

**Duration (지속 시간)**

| 토큰 | 값 | 용도 |
|------|-----|------|
| `duration.instant` | 100ms | 토글, 체크박스 |
| `duration.fast` | 150ms | 호버, 포커스 |
| `duration.normal` | 250ms | 모달 열기, 탭 전환 |
| `duration.slow` | 400ms | 페이지 전환 |
| `duration.slower` | 600ms | 복잡한 애니메이션 |

**Easing (가속도 곡선)**

| 토큰 | 값 | 용도 |
|------|-----|------|
| `easing.default` | `cubic-bezier(0.4, 0, 0.2, 1)` | 일반 전환 |
| `easing.in` | `cubic-bezier(0.4, 0, 1, 1)` | 요소 퇴장 |
| `easing.out` | `cubic-bezier(0, 0, 0.2, 1)` | 요소 등장 |
| `easing.spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 탄성 효과 |

**Delay (지연)**

| 토큰 | 값 | 용도 |
|------|-----|------|
| `delay.none` | 0ms | 즉시 시작 |
| `delay.short` | 75ms | 순차 애니메이션 간격 |
| `delay.medium` | 150ms | 툴팁 표시 대기 |

### 5.2 Motion Presets

```css
/* fadeIn */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

/* slideUp */
@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(16px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* scaleIn */
@keyframes scaleIn {
  from {
    opacity: 0;
    transform: scale(0.95);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}
```

**Preset 적용 유틸리티**

```css
.animate-fadeIn   { animation: fadeIn var(--duration-normal) var(--easing-out); }
.animate-slideUp  { animation: slideUp var(--duration-normal) var(--easing-out); }
.animate-scaleIn  { animation: scaleIn var(--duration-fast) var(--easing-spring); }
```

**접근성: 모션 감소 대응**

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 6.2 SVG Sprite Sheet

**빌드 파이프라인**

```
개별 SVG 파일들
    ↓ (svgo 최적화)
최적화된 SVG
    ↓ (svg-sprite 번들링)
sprite.svg (단일 파일)
    ↓ (빌드 시 인라인 또는 외부 참조)
프로덕션 배포
```

**사용 방법**

```tsx
// Icon 컴포넌트
function Icon({ name, size = 24, className }: IconProps) {
  return (
    <svg width={size} height={size} className={className}>
      <use href={`/icons/sprite.svg#${name}`} />
    </svg>
  );
}

// 사용 예시
<Icon name="search" size={20} />
<Icon name="learnform-logo" size={32} />
```

**HTTP 요청 감소 효과**

| 방식 | 아이콘 50개 기준 HTTP 요청 | 번들 크기 |
|------|---------------------------|-----------|
| 개별 SVG import | 50회 | 분산 |
| React 컴포넌트 (인라인) | 0회 | JS 번들 증가 |
| **SVG Sprite Sheet** | **1회** | **~15KB (gzip)** |

## 8. 성과 목표

### 8.1 핵심 KPI

| 지표 | 현재 | 목표 | 측정 방법 |
|------|------|------|-----------|
| **컴포넌트 재사용률** | ~40% | **> 80%** | 공유 컴포넌트 사용 비율 |
| 디자인-코드 일관성 | 수동 검증 | 자동 검증 | Chromatic 시각적 테스트 |
| 컴포넌트 문서화율 | ~10% | > 95% | Storybook 스토리 커버리지 |
| 신규 페이지 구현 시간 | ~5일 | ~2일 | 템플릿 기반 조립 |
| 디자인 토큰 커버리지 | 색상만 | 전체 | 토큰 기반 스타일 비율 |
| 접근성 준수율 | 미측정 | WCAG 2.1 AA | axe-core 자동 테스트 |

### 8.2 단계별 로드맵

```
Phase 1 (1~2개월) ─── 기반 구축
├── Storybook 8 환경 설정
├── 기존 컴포넌트 Storybook 마이그레이션
├── Design Token JSON 초기 정의
└── 아이콘 Sprite Sheet 빌드 파이프라인

Phase 2 (3~4개월) ─── 체계화
├── W3C Design Token 표준 전환 완료
├── Figma Variables ↔ Token Studio 연동
├── 컴포넌트 카탈로그 (Atoms + Molecules) 완성
├── 다크모드 구현
└── 애니메이션 토큰 체계화

Phase 3 (5~6개월) ─── 고도화
├── Organisms + Templates 완성
├── Container Queries 전면 도입
├── 서비스별 브랜드 테마 분리
├── MDX 문서 자동 생성 파이프라인
└── Chromatic 시각적 회귀 테스트 CI 연동

Phase 4 (7개월~) ─── 운영 최적화
├── 컴포넌트 재사용률 80% 달성 검증
├── 디자인 시스템 거버넌스 프로세스 수립
├── 커뮤니티 기여 모델 (RFC 프로세스)
└── 멀티 플랫폼 토큰 확장 (모바일 앱)
```
