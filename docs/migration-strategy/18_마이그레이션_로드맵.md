### 2.2 캐싱 전략

#### Service Worker 캐시

```javascript
// sw.js — Workbox 기반
import { precacheAndRoute } from 'workbox-precaching';
import { registerRoute } from 'workbox-routing';
import { StaleWhileRevalidate, CacheFirst } from 'workbox-strategies';

// 앱 셸 사전 캐시
precacheAndRoute(self.__WB_MANIFEST);

// API 응답: Stale-While-Revalidate
registerRoute(
  ({ url }) => url.pathname.startsWith('/api/'),
  new StaleWhileRevalidate({ cacheName: 'api-cache' })
);

// 정적 에셋: Cache First
registerRoute(
  ({ request }) => ['image', 'font', 'style', 'script'].includes(request.destination),
  new CacheFirst({
    cacheName: 'static-assets',
    plugins: [
      new ExpirationPlugin({ maxEntries: 200, maxAgeSeconds: 30 * 24 * 60 * 60 }),
    ],
  })
);
```

#### Edge 캐시 정책

| 리소스 유형 | Cache-Control | 비고 |
|------------|---------------|------|
| HTML | `no-cache, must-revalidate` | 항상 최신 확인 |
| JS/CSS (해시) | `public, max-age=31536000, immutable` | 1년, 파일명에 해시 포함 |
| 이미지 | `public, max-age=86400, s-maxage=604800` | CDN 7일, 브라우저 1일 |
| API 응답 | `private, max-age=0, s-maxage=60` | Edge 1분 캐시 |
| 비디오 매니페스트 | `public, max-age=300` | 5분 캐시 |

### 5.1 A/B 테스트 인프라

```typescript
// Edge에서 실행되는 A/B 테스트
export default {
  async fetch(request: Request) {
    const userId = getUserId(request);
    const variant = assignVariant(userId, 'hero-redesign');

    const response = await fetch(request);
    const html = await response.text();

    // Edge에서 변형 적용 (클라이언트 깜빡임 없음)
    const modified = variant === 'B'
      ? html.replace('hero-v1', 'hero-v2')
      : html;

    return new Response(modified, response);
  },
};
```

- Edge 기반 서버 사이드 A/B (깜빡임 Zero)
- 실험 관리 대시보드
- 통계적 유의성 자동 판정 (베이지안)
- 주요 실험 대상: CTA 문구, 가격 페이지 레이아웃, 온보딩 플로우

### 5.2 AI 기반 개인화

```
사용자 행동 데이터 → BigQuery ML → 추천 모델 → Edge 캐시 개인화
```

- 학습 이력 기반 강좌 추천
- 사용자 수준별 콘텐츠 난이도 조절
- 학습 시간대 분석 → 최적 알림 시간 결정
- 개인화된 랜딩 페이지 (재방문 사용자)

### 5.3 글로벌 Edge 배포

#### 6개 리전 배포

| 리전 | 위치 | 서비스 | 예상 TTFB |
|------|------|--------|----------|
| asia-northeast1 | 도쿄 | Cloud Run + AlloyDB Read Replica | < 30ms |
| asia-northeast3 | 서울 | Cloud Run + AlloyDB Primary | < 20ms |
| asia-southeast1 | 싱가포르 | Cloud Run + AlloyDB Read Replica | < 40ms |
| us-central1 | 아이오와 | Cloud Run + AlloyDB Read Replica | < 40ms |
| europe-west1 | 벨기에 | Cloud Run + AlloyDB Read Replica | < 40ms |
| asia-east1 | 대만 | Cloud Run + AlloyDB Read Replica | < 35ms |

#### Edge 렌더링

```
Cloudflare Workers (전역 300+ PoP)
  ├── 정적 페이지: KV Store에서 즉시 반환 (TTFB < 10ms)
  ├── SSR 페이지: 가장 가까운 Cloud Run으로 프록시
  └── API: Geo-routing으로 최적 리전 선택
```

### 5.4 실시간 분석 대시보드

```
[RUM 데이터] → [Pub/Sub] → [Dataflow] → [BigQuery]
                                              ↓
                                        [Looker Studio]
                                              ↓
                                    실시간 대시보드 + 알림
```

#### 대시보드 패널 구성

| 패널 | 지표 | 갱신 주기 |
|------|------|----------|
| Core Web Vitals | LCP, INP, CLS (P75, P95) | 1분 |
| 글로벌 TTFB 맵 | 리전별 TTFB 히트맵 | 5분 |
| 에러율 | JS 에러, API 에러 | 실시간 |
| 캐시 효율 | CDN 히트율, SW 캐시율 | 5분 |
| 사용자 경험 | 이탈률, 전환율 | 10분 |
