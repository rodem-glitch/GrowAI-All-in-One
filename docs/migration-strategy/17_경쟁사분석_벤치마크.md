## 4. 디자인 벤치마크

### 4.1 다크 테마 트렌드

**업계 동향:**
- AI/영상 도구 업계에서 다크 테마가 주류 (Runway, Luma AI)
- 영상 콘텐츠의 시각적 임팩트 극대화
- 장시간 작업 시 눈의 피로 감소

**NEWKL 적용 방향:**
- 다크 테마 기본 + 라이트 테마 전환 지원
- 교육 콘텐츠 미리보기 시 다크 배경으로 몰입감 강화
- NEWKL 브랜드 컬러(블루/퍼플 계열) 그라데이션 액센트

| SEO | 80~90 | 95 (HeyGen) | **100** |

### 5.2 로딩 속도: 업계 Top 3 달성 전략

**목표:**
- TTFB < 200ms (서울 리전 Cloud Run + Cloud CDN)
- FCP < 0.8s (인라인 크리티컬 CSS + 폰트 프리로드)
- LCP < 1.5s (AVIF 히어로 이미지 + Edge 캐싱)
- INP < 100ms (React Server Components + 선택적 하이드레이션)
- CLS < 0.02 (이미지/영상 사이즈 사전 지정)

**기술적 구현:**

```
1. 서버 최적화
   - GCP 서울 리전(asia-northeast3) Cloud Run 배포
   - Cloud CDN 글로벌 엣지 캐싱
   - Brotli 압축 적용

2. 프론트엔드 최적화
   - Next.js 14 App Router + React Server Components
   - 라우트 기반 코드 스플리팅
   - next/image 자동 최적화 (AVIF/WebP)
   - 폰트: next/font 로컬 최적화 (Pretendard)

3. 미디어 최적화
   - 영상: HLS 적응형 스트리밍 + Cloud CDN
   - 이미지: AVIF > WebP > JPEG 폴백 체인
   - 지연 로딩: Intersection Observer 기반
   - 프리로드: 위 폴드 에셋 선제 로딩

4. 번들 최적화
   - 초기 JS 번들 < 500KB (gzip)
   - Tree shaking + 동적 import
   - 서드파티 스크립트 지연 로딩 (Analytics, Chat 등)
```
