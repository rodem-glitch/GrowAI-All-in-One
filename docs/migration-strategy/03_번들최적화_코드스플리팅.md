# 03. 번들 최적화 & 코드 스플리팅 전략

> NEWKL AI Video 플랫폼 — 프론트엔드 번들 최적화 가이드

---

## 1. 현재 번들 분석

### 청크 구성 현황

| 청크 이름 | 포함 라이브러리 | 예상 크기 (gzip) |
|-----------|----------------|------------------|
| `react-vendor` | react, react-dom, react-router-dom | ~45KB |
| `ui-vendor` | lucide-react, motion(framer-motion), class-variance-authority, clsx | ~35KB |
| `i18n-vendor` | i18next, react-i18next, i18next-browser-languagedetector | ~15KB |
| `app` (엔트리) | 애플리케이션 코드 + 라우터 설정 | ~20KB |
| 기타 lazy 청크 | 페이지별 코드 | 페이지당 ~5-15KB |

### 전체 번들 예상 크기

```
초기 로드 (Critical Path):
  react-vendor.js    ~45KB (gzip)
  ui-vendor.js       ~35KB (gzip)
  i18n-vendor.js     ~15KB (gzip)
  app.js             ~20KB (gzip)
  ──────────────────────────
  합계               ~115KB (gzip)

문제: 초기 로드 목표 50KB 대비 약 2.3배 초과
```

## 3. 코드 스플리팅 고도화

### 3.1 Route-based Splitting (적용 완료)

```tsx
// 이미 lazy()로 라우트 레벨 스플리팅 적용됨
const Dashboard = lazy(() => import('./pages/Dashboard'));
const VideoEditor = lazy(() => import('./pages/VideoEditor'));
const ProjectList = lazy(() => import('./pages/ProjectList'));
```

### 3.2 Component-level Splitting (무거운 컴포넌트)

비디오 플랫폼 특성상 무거운 컴포넌트를 동적 로드로 분리한다.

```tsx
// 비디오 플레이어 — 초기 로드 불필요, 사용 시점에 로드
const VideoPlayer = lazy(() => import('./components/VideoPlayer'));

// 리치 텍스트 에디터 — 편집 페이지에서만 필요
const RichTextEditor = lazy(() => import('./components/RichTextEditor'));

// 차트/분석 대시보드 — 분석 탭 진입 시 로드
const AnalyticsChart = lazy(() => import('./components/AnalyticsChart'));

// AI 자막 편집기 — 자막 작업 시에만 로드
const SubtitleEditor = lazy(() => import('./components/SubtitleEditor'));
```

**Suspense 래퍼 패턴:**

```tsx
import { Suspense, lazy } from 'react';
import { Skeleton } from '@/components/ui/Skeleton';

function VideoPage() {
  return (
    <Suspense fallback={<Skeleton className="w-full aspect-video" />}>
      <VideoPlayer src={videoUrl} />
    </Suspense>
  );
}
```

### 3.3 Library-level Splitting (동적 import)

무거운 라이브러리를 사용 시점에 동적으로 로드한다.

```tsx
// 날짜 처리 — 필요 시점에만 로드
async function formatDate(date: Date, locale: string) {
  const { format } = await import('date-fns');
  const localeModule = await import(`date-fns/locale/${locale}`);
  return format(date, 'PPP', { locale: localeModule.default });
}

// 마크다운 렌더링 — 콘텐츠 표시 시에만
const MarkdownRenderer = lazy(() => import('react-markdown'));

// 파일 업로드 — 업로드 버튼 클릭 시
async function handleUpload(file: File) {
  const { uploadToStorage } = await import('@/lib/storage');
  return uploadToStorage(file);
}

// 엑셀 내보내기 — 내보내기 실행 시
async function exportToExcel(data: unknown[]) {
  const XLSX = await import('xlsx');
  const worksheet = XLSX.utils.json_to_sheet(data);
  // ...
}
```

## 4. Tree Shaking 최적화

### 4.1 lucide-react: 개별 아이콘만 import

```tsx
// BAD — 전체 아이콘 번들 포함 (~180KB)
import { Play, Pause, Settings } from 'lucide-react';

// GOOD — 개별 아이콘만 포함 (아이콘당 ~1KB)
import { Play } from 'lucide-react/dist/esm/icons/play';
import { Pause } from 'lucide-react/dist/esm/icons/pause';
import { Settings } from 'lucide-react/dist/esm/icons/settings';
```

**별칭 설정으로 편의성 유지:**

```ts
// vite.config.ts
export default defineConfig({
  resolve: {
    alias: {
      '@icons': 'lucide-react/dist/esm/icons',
    },
  },
});
```

```tsx
// 사용처 — 깔끔한 import 유지
import { Play } from '@icons/play';
import { Pause } from '@icons/pause';
```

### 4.2 i18next: 필요 모듈만

```ts
// BAD — 전체 패키지
import i18next from 'i18next';

// GOOD — 핵심 모듈만
import { createInstance } from 'i18next/createInstance';
import { initReactI18next } from 'react-i18next/initReactI18next';
```

**언어 리소스 동적 로드:**

```ts
// 초기엔 현재 언어만 로드, 나머지는 필요 시 로드
i18next.init({
  lng: 'ko',
  resources: {
    ko: { translation: koTranslation }, // 초기 번들에 포함
  },
  // 다른 언어는 lazy 로드
  backend: {
    loadPath: '/locales/{{lng}}/{{ns}}.json',
  },
});
```

### 4.3 motion (framer-motion): 사용 컴포넌트만

```tsx
// BAD — 전체 패키지 (~60KB gzip)
import { motion, AnimatePresence } from 'motion/react';

// GOOD — 필요한 것만 개별 import
import { m, LazyMotion, domAnimation } from 'motion/react';

// 최소 번들: LazyMotion + domAnimation (~5KB gzip)
function App() {
  return (
    <LazyMotion features={domAnimation}>
      <m.div animate={{ opacity: 1 }} />
    </LazyMotion>
  );
}
```

**고급 애니메이션이 필요한 경우 동적 로드:**

```tsx
// 3D 애니메이션 등 고급 기능은 별도 로드
const features = () => import('motion/react').then(mod => mod.domMax);

function AdvancedAnimation() {
  return (
    <LazyMotion features={features} strict>
      <m.div layout layoutId="shared" />
    </LazyMotion>
  );
}
```

## 5. 압축 전략

### 5.1 Brotli vs Gzip 비교

| 항목 | Gzip | Brotli |
|------|------|--------|
| 압축률 | 기준 | 15-20% 추가 절감 |
| 압축 속도 | 빠름 | 느림 (사전 압축으로 해결) |
| 브라우저 지원 | 거의 100% | 97%+ (HTTPS 필수) |
| 권장 | 폴백용 | 기본 사용 |

### 5.2 Vite 빌드 시 사전 압축

```ts
// vite.config.ts
import viteCompression from 'vite-plugin-compression';

export default defineConfig({
  plugins: [
    // Brotli 사전 압축
    viteCompression({
      algorithm: 'brotliCompress',
      ext: '.br',
      threshold: 1024, // 1KB 이상만 압축
    }),
    // Gzip 폴백
    viteCompression({
      algorithm: 'gzip',
      ext: '.gz',
      threshold: 1024,
    }),
  ],
});
```

### 5.3 Nginx brotli_static 설정

```nginx
server {
    listen 443 ssl http2;
    server_name video.newkl.ai;

    # Brotli 사전 압축 파일 우선 서빙
    brotli_static on;
    gzip_static on;

    # 동적 Brotli 압축 (사전 압축 파일 없는 경우)
    brotli on;
    brotli_comp_level 6;
    brotli_types
        text/plain
        text/css
        text/javascript
        application/javascript
        application/json
        application/xml
        image/svg+xml;

    # 정적 파일 캐싱
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        add_header Vary "Accept-Encoding";
    }
}
```

**압축 효과 예측:**

```
원본 → Gzip → Brotli
115KB → 115KB → ~95KB (약 17% 추가 절감)
```

## 6. 리소스 힌트

### 6.1 modulepreload: 핵심 청크

현재 라우트에서 반드시 필요한 모듈을 사전 로드한다.

```html
<!-- index.html -->
<head>
  <!-- 핵심 벤더 청크 — 즉시 파싱 및 실행 준비 -->
  <link rel="modulepreload" href="/assets/react-vendor.[hash].js" />
  <link rel="modulepreload" href="/assets/app.[hash].js" />

  <!-- modulepreload는 preload와 달리 JS 모듈 그래프를 따라감 -->
  <!-- 브라우저가 의존성까지 함께 fetch -->
</head>
```

**Vite 자동 설정:**

```ts
// vite.config.ts
export default defineConfig({
  build: {
    modulePreload: {
      polyfill: true, // 미지원 브라우저 폴리필
    },
  },
});
```

### 6.2 prefetch: 다음 라우트 예측

사용자가 이동할 가능성이 높은 라우트의 청크를 유휴 시간에 미리 로드한다.

```tsx
// 라우트 프리페치 훅
function usePrefetchRoute(routePath: string) {
  useEffect(() => {
    const link = document.createElement('link');
    link.rel = 'prefetch';
    link.href = routePath;
    link.as = 'script';
    document.head.appendChild(link);

    return () => {
      document.head.removeChild(link);
    };
  }, [routePath]);
}

// 네비게이션에서 hover 시 프리페치
function NavLink({ to, children }: NavLinkProps) {
  const handleMouseEnter = () => {
    // 라우트 모듈을 미리 import
    const routeModule = routeMap[to];
    if (routeModule) {
      routeModule(); // lazy import 함수 실행
    }
  };

  return (
    <Link to={to} onMouseEnter={handleMouseEnter}>
      {children}
    </Link>
  );
}
```

### 6.3 dns-prefetch: 외부 도메인

외부 API 및 CDN 도메인의 DNS 조회를 미리 수행한다.

```html
<head>
  <!-- AI API 서버 -->
  <link rel="dns-prefetch" href="//api.newkl.ai" />
  <link rel="preconnect" href="https://api.newkl.ai" crossorigin />

  <!-- 비디오 스토리지 (GCS) -->
  <link rel="dns-prefetch" href="//storage.googleapis.com" />
  <link rel="preconnect" href="https://storage.googleapis.com" crossorigin />

  <!-- 폰트 CDN -->
  <link rel="dns-prefetch" href="//fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.googleapis.com" crossorigin />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />

  <!-- 분석/모니터링 -->
  <link rel="dns-prefetch" href="//cdn.segment.com" />
</head>
```

## 7. Vite 빌드 설정 최적화

### 7.1 rollupOptions.output.manualChunks 세분화

```ts
// vite.config.ts
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks: (id: string) => {
          // React 핵심 — 거의 변경 없음, 장기 캐싱
          if (id.includes('react-dom') || id.includes('react/')) {
            return 'react-vendor';
          }

          // 라우터 — React와 분리하여 캐시 효율 향상
          if (id.includes('react-router')) {
            return 'router-vendor';
          }

          // UI 유틸리티 — 자주 사용하지만 가벼움
          if (id.includes('clsx') || id.includes('class-variance-authority') || id.includes('tailwind-merge')) {
            return 'ui-utils';
          }

          // 아이콘 — 사용하는 아이콘만 포함
          if (id.includes('lucide-react')) {
            return 'icons';
          }

          // 애니메이션 — 필요 시 로드
          if (id.includes('motion') || id.includes('framer-motion')) {
            return 'animation';
          }

          // i18n — 초기 로드에서 분리 가능
          if (id.includes('i18next')) {
            return 'i18n';
          }

          // 상태 관리
          if (id.includes('zustand') || id.includes('@tanstack/react-query')) {
            return 'state';
          }

          // 나머지 node_modules
          if (id.includes('node_modules')) {
            return 'vendor-misc';
          }
        },
      },
    },
  },
});
```

### 7.2 minify: terser with compress options

```ts
// vite.config.ts
export default defineConfig({
  build: {
    minify: 'terser',
    terserOptions: {
      compress: {
        drop_console: true,       // console.log 제거
        drop_debugger: true,      // debugger 제거
        pure_funcs: ['console.log', 'console.info'], // 순수 함수 제거
        passes: 2,                // 2회 압축 패스
        ecma: 2020,               // 최신 문법 활용한 압축
        unsafe_arrows: true,      // 화살표 함수 최적화
        unsafe_methods: true,     // 메서드 축약
      },
      mangle: {
        safari10: true,           // Safari 10 호환
        properties: false,        // 속성명 난독화 비활성화 (안전)
      },
      format: {
        comments: false,          // 주석 제거
        ascii_only: true,         // ASCII 문자만 (한글 이스케이프)
      },
    },
  },
});
```

### 7.4 최적화 후 예상 번들 크기

```
최적화 후 초기 로드 (Critical Path):

  react-vendor.js     ~40KB → Brotli ~34KB
  app.js              ~8KB  → Brotli ~7KB
  ui-utils.js         ~3KB  → Brotli ~2.5KB
  ────────────────────────────────────
  합계                ~51KB → Brotli ~43.5KB  (목표 50KB 달성)

지연 로드 (Deferred):
  router-vendor.js    ~8KB

  animation.js        ~5KB (domAnimation만)
  i18n.js             ~12KB
  state.js            ~8KB
  vendor-misc.js      ~10KB
  ────────────────────────────────────
  지연 합계           ~48KB (사용자 인터랙션 후 로드)
```

**CI/CD 파이프라인 통합:**

```yaml
# .github/workflows/bundle-check.yml
name: Bundle Size Check
on: [pull_request]
jobs:
  bundle-size:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: pnpm install --frozen-lockfile
      - run: pnpm build
      - name: Check bundle size
        run: |
          TOTAL_SIZE=$(du -sb dist/assets/*.js | awk '{total += $1} END {print total}')
          MAX_SIZE=204800  # 200KB (비압축 기준)
          if [ "$TOTAL_SIZE" -gt "$MAX_SIZE" ]; then
            echo "Bundle size exceeded: ${TOTAL_SIZE} bytes (max: ${MAX_SIZE})"
            exit 1
          fi
      - uses: preactjs/compressed-size-action@v2
        with:
          repo-token: "${{ secrets.GITHUB_TOKEN }}"
          pattern: "dist/assets/**/*.{js,css}"
```
