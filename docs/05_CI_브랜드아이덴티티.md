# GrowAI 브랜드 아이덴티티 (CI 가이드)

## 1. 브랜드 이름

- **영문**: GrowAI
- **한글**: 그로우AI

## 2. 슬로건

> "AI로 성장하는 모든 것"

## 3. 도메인

- **공식 도메인**: growai.co.kr

---

## 4. 로고 (CI)

### 4.1 로고 구성 요소

| 요소 | 사양 |
|------|------|
| 전체 크기 | 34 x 34 px |
| 배경 형태 | 라운드 사각형 (rx=8) |
| 배경 색상 | 코발트 블루 그라디언트 (primaryDark → primary) |
| 심볼 | 흰색 월계수 잎 |
| 잎 방향 | 우상단 → 좌하단 대각선 배치 |
| 잎맥 | 중심선 표현 |
| 하이라이트 | 우측 상단 radialGradient 적용 |

### 4.2 로고 SVG 사양

- **포맷**: SVG
- **배경 그라디언트**: primaryDark(`#107f9e`) → primary(`#14a1c8`) 선형 그라디언트
- **심볼 색상**: `#FFFFFF` (순백)
- **하이라이트 효과**: 우측 상단 모서리에 radialGradient로 광택 표현

## 5. CI 의미 해석

### 5.1 심볼 — 월계수 잎

| 요소 | 의미 |
|------|------|
| **월계수 잎** | 승리, 학문적 성취, 명예 |
| **한 잎** | Simple is Best, 절제미 |
| **대각선 배치** | 지식이 위에서 아래로 전달되는 교육의 흐름 |
| **잎맥 (중심선)** | 학습의 경로 — CREATOR 7단계를 상징 |
| **여백** | 한국적 여백의 미, 학습자의 성장 공간 |

### 5.2 색상 — 코발트 블루

- **신뢰**: 교육 플랫폼으로서의 안정감
- **지혜**: AI 기반 학습의 깊이
- **깊이**: 단순한 도구를 넘어선 교육 철학

### 5.3 브랜드 철학 한 문장

> "하나의 잎, 하나의 길. 배움은 단순함에서 시작된다."

## 7. 타이포그래피

### 7.1 주요 서체

| 우선순위 | 서체 | 용도 |
|----------|------|------|
| **Primary** | Pretendard | 한글/영문 본문 및 제목 |


## 8. 서브 브랜드 규칙

### 8.1 조합 원칙

각 TLA(Three-Letter Acronym) 서비스는 **GrowAI 로고 + 서비스명** 조합으로 표기한다.

### 8.2 표기 형식

```
[로고] GrowAI {서비스명}
```

### 8.3 적용 예시

| 표기 | 서비스 |
|------|--------|
| [로고] GrowAI MAP | 학습 경로 설계 서비스 |
| [로고] GrowAI LMS | 학습 관리 시스템 |

### 8.4 서브 브랜드 규정

- 로고와 서비스명 사이에 항상 `GrowAI` 브랜드명을 포함한다.
- 서비스명은 대문자 TLA로 표기한다.
- 로고 크기와 서비스명 텍스트 간 비율을 일관되게 유지한다.
