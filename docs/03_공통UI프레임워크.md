# 03. 공통 UI 프레임워크

GrowAI 플랫폼(LearnForm + LMS)에서 공유하는 UI 프레임워크 설계 문서.

---

## 1. 디자인 시스템 개요

### 기술 기반

| 항목 | 기술 |
|------|------|
| 스타일링 | Tailwind CSS 4 |
| 동적 테마 | CSS Custom Properties |
| 아키텍처 | 컴포넌트 기반 (React) |

### 핵심 원칙

- **Tailwind CSS 4 기반**: 유틸리티 퍼스트 접근으로 일관된 스타일링 제공. Tailwind 4의 새로운 엔진과 설정 방식을 활용한다.
- **CSS Custom Properties로 동적 테마**: `--primary`, `--primary-dark` 등 CSS 변수를 통해 런타임에 테마를 전환할 수 있다. JavaScript 번들 없이 CSS 레벨에서 테마가 적용된다.
- **컴포넌트 기반 아키텍처**: 재사용 가능한 컴포넌트 단위로 UI를 구성한다. LearnForm(마케팅 사이트)과 LMS(학습 관리 시스템) 양쪽에서 공통 컴포넌트를 공유한다.

---

## 2. ThemeContext (공통 테마)

### 개요

전체 애플리케이션의 시각적 테마를 관리하는 React Context. 다크모드와 액센트 컬러를 제어한다.

### 다크모드

- `html` 요소에 `dark` 클래스를 토글하여 다크모드를 전환한다.
- Tailwind의 `dark:` 접두사 변형과 연동된다.
- 사용자 설정은 `localStorage`에 저장되어 재방문 시 유지된다.

```tsx
// 다크모드 토글 예시
<html class="dark">  <!-- 다크모드 활성 -->
<html class="">      <!-- 라이트모드 -->
```

### 5가지 액센트 컬러

| 컬러명 | 용도 |
|--------|------|
| `teal` | 기본 (Primary) |
| `blue` | 대안 1 |
| `purple` | 대안 2 |
| `orange` | 대안 3 |
| `green` | 대안 4 |

액센트 컬러 선택 시 아래 CSS 변수가 동적으로 업데이트된다:

```css
:root {
  --primary: <선택된 액센트 컬러>;
  --primary-dark: <선택된 액센트 컬러의 어두운 변형>;
}
```

### useTheme() 훅

```tsx
const { theme, toggleDarkMode, accentColor, setAccentColor } = useTheme();
```

| 반환값 | 타입 | 설명 |
|--------|------|------|
| `theme` | `'light' \| 'dark'` | 현재 테마 모드 |
| `toggleDarkMode` | `() => void` | 다크모드 토글 |
| `accentColor` | `AccentColor` | 현재 액센트 컬러 |
| `setAccentColor` | `(color: AccentColor) => void` | 액센트 컬러 변경 |

## 3. LanguageContext (다국어)

### 개요

한국어/영어 전환을 관리하는 React Context. 모든 UI 텍스트를 번역 키 기반으로 처리한다.

### 지원 언어

| 코드 | 언어 |
|------|------|
| `ko` | 한국어 (기본) |
| `en` | 영어 |

### Translations 타입 시스템

번역 데이터는 타입 안전하게 관리된다. 모든 번역 키는 `Translations` 타입으로 정의되어 컴파일 타임에 누락된 번역을 감지할 수 있다.

```tsx
type Translations = {
  nav: {
    home: string;
    courses: string;
    pricing: string;
    // ...
  };
  hero: {
    title: string;
    subtitle: string;
    // ...
  };
  // ...
};
```

### useLanguage() 훅

```tsx
const { language, setLanguage, t } = useLanguage();
```

| 반환값 | 타입 | 설명 |
|--------|------|------|
| `language` | `'ko' \| 'en'` | 현재 언어 |
| `setLanguage` | `(lang: Language) => void` | 언어 전환 |
| `t` | `Translations` | 현재 언어의 번역 객체 |

## 4. 공통 컴포넌트

### Button

다양한 스타일과 크기를 지원하는 범용 버튼 컴포넌트.

**Variants (4종)**

| Variant | 설명 | 스타일 |
|---------|------|--------|
| `primary` | 주요 액션 | 채워진 배경, 흰색 텍스트 |
| `secondary` | 보조 액션 | 연한 배경, 프라이머리 텍스트 |
| `outline` | 외곽선 | 테두리만, 투명 배경 |
| `ghost` | 최소 스타일 | 배경 없음, 호버 시 연한 배경 |

**Sizes (3종)**

| Size | 설명 |
|------|------|
| `sm` | 소형 (패딩 축소) |
| `md` | 중형 (기본값) |
| `lg` | 대형 (패딩 확대) |

### Badge

상태나 카테고리를 표시하는 라벨 컴포넌트.

| Variant | 용도 | 색상 |
|---------|------|------|
| `primary` | 기본 표시 | 프라이머리 |
| `success` | 완료/성공 | 녹색 |
| `warning` | 주의/진행중 | 주황색 |
| `info` | 정보/안내 | 파란색 |

### Avatar

사용자 프로필 이미지를 원형으로 표시하는 컴포넌트. 이미지가 없을 경우 이름 이니셜을 표시한다.

### Tabs

탭 형태의 네비게이션 컴포넌트. 선택된 탭에 액센트 컬러 하단 보더가 표시된다.

### SearchBar

검색 아이콘과 입력 필드를 결합한 검색 컴포넌트. 포커스 시 테두리 색상이 프라이머리로 변경된다.

### SectionHeading

섹션 제목과 부제목을 표시하는 컴포넌트. 상단에 액센트 컬러 장식선이 포함된다.

### ScrollToTop

스크롤이 일정 위치 이상 내려갔을 때 나타나는 상단 이동 버튼. 클릭 시 페이지 최상단으로 부드럽게 스크롤된다.

## 5. 레이아웃 컴포넌트

### Layout

`Outlet` 기반 페이지 래퍼. React Router의 중첩 라우팅과 연동되어 공통 레이아웃(헤더, 푸터)을 유지하면서 내부 콘텐츠만 교체한다.

### TopNav

LMS 전용 상단 네비게이션 바.
- 로고, 검색바, 알림 아이콘, 사용자 프로필 메뉴 포함
- 다크모드/라이트모드에 따라 배경색 전환

### Header

LearnForm 마케팅 사이트용 헤더.
- 메가메뉴 드롭다운 지원
- 스크롤 시 축소 애니메이션
- 모바일에서는 햄버거 메뉴로 전환

### Footer

다크 배경 4컬럼 푸터.
- 4개 컬럼: 회사 소개, 제품, 지원, 법적 고지
- 하단에 저작권 및 SNS 링크
- 다크 배경(`bg-gray-900`)에 밝은 텍스트

### MobileMenu

모바일 환경에서 표시되는 전체 화면 메뉴.
- 슬라이드 인/아웃 애니메이션
- 아코디언 형태의 서브메뉴 지원

### Logo

월계수 잎 모양의 SVG 로고 컴포넌트.
- 크기 조절 가능
- 테마에 따라 색상 자동 전환

## 6. 섹션 컴포넌트 (LearnForm 재사용)

LearnForm 마케팅 페이지에서 사용되며, 필요 시 다른 페이지에서도 재사용 가능한 섹션 단위 컴포넌트.

| 컴포넌트 | 설명 |
|----------|------|
| `Hero` | 메인 히어로 배너. 제목, 부제목, CTA 버튼 |
| `Features` | 주요 기능 소개 그리드 |
| `Showcase` | 제품 스크린샷/데모 쇼케이스 |
| `Workflow` | CREATOR 워크플로우 단계 시각화 |
| `Solutions` | 활용 분야별 솔루션 소개 |
| `Testimonials` | 사용자 후기/추천사 캐러셀 |
| `Privacy` | 개인정보 보호 및 보안 안내 |
| `Pricing` | 요금제 비교 카드 |
| `FAQ` | 자주 묻는 질문 아코디언 |
| `Download` | 앱/리소스 다운로드 안내 |
| `CTA` | 행동 유도 배너 (가입/문의) |
| `Integrations` | 연동 가능 서비스 로고 그리드 |

## 7. 도메인 컴포넌트 (LMS 전용)

LMS(학습 관리 시스템) 화면에서 사용되는 도메인 특화 컴포넌트.

### 학습 콘텐츠

| 컴포넌트 | 설명 |
|----------|------|
| `CourseCard` | 개별 강좌 카드. 썸네일, 제목, 진행률, 강사 정보 표시 |
| `CourseGrid` | `CourseCard`를 반응형 그리드로 배치하는 레이아웃 컴포넌트 |
| `LearningPathCard` | 학습 경로 카드. 포함된 강좌 수, 예상 소요 시간, 난이도 표시 |
| `RatingStars` | 별점 표시 컴포넌트. 0.5 단위 반별 지원 |

### 소셜/커뮤니티

| 컴포넌트 | 설명 |
|----------|------|
| `ActivityFeed` | 최근 활동 타임라인. 학습 완료, 배지 획득 등 이벤트 표시 |
| `DiscussionCard` | 토론 게시글 카드. 제목, 작성자, 댓글 수, 좋아요 수 표시 |
| `LeaderboardRow` | 리더보드 행. 순위, 사용자 정보, 점수 표시 |
| `ProjectCard` | 프로젝트 과제 카드. 제출 상태, 마감일, 팀원 정보 표시 |
| `UserProfileCard` | 사용자 프로필 요약 카드. 아바타, 이름, 학습 통계 표시 |

```css
:root {

  --primary-dark: #0e7a9a;
  --text-primary: #242727;
  --text-secondary: #555c5d;
  --text-tertiary: #303436;
  --border-default: #d7dadb;
  --bg-light: #fbfbfb;
  --bg-dark: #0f1112;
}

html.dark {
  --text-primary: #e5e7eb;
  --text-secondary: #9ca3af;
  --border-default: #374151;
}
```
