" — " (em dash with spaces) 문자를 사용하지 않는다.

**Why:** 사용자가 해당 문자 사용을 명시적으로 금지함.
**How to apply:** 코드, i18n 텍스트, UI 문구 작성 시 " — " 대신 마침표+줄바꿈 또는 다른 구분 방식을 사용할 것.
